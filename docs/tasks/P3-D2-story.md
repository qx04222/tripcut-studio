# 任务卡 P3-D2:旅行章节与故事板(Rough Cut 对象)

状态:排队(D1 之后派发)。实施:Codex。主审:Claude。

## 目标
规格 §7/竞品结论(Prelude Rough Cut+镜头槽位):自动按拍摄时间断档聚章节,故事板把精选组织成可排序叙事,交付粗剪按故事序输出。

## 范围
- 自动章节:按 captured_at 间隔聚类(断档>45 分钟分章;GPS 可用时距离>2km 也分),章节命名"第N段·HH:MM-HH:MM";migration 0010:`chapters(id,title,start_at,end_at)`+`clips.chapter_id`;导入完成后自动跑(job `chapterize`,幂等)
- 故事板视图(筛片页新模式或独立视图,实现自选并写明):按章节分组展示精选(段/整条),拖拽排序(order 字段落库 `story_order` 表 migration 同 0010);未入故事板的精选在「候选区」
- 章节可改名/合并(简单 UI);一切可撤销(顺序变更落库,无删除)
- 交付:粗剪与片段序号改按 story_order(无故事板时退回拍摄时间序);CSV 加「章节」列
- 中文文案;token 配色;字号用 C7 的 token 体系
## 验收
cargo ≥6(断档聚类边界/幂等/排序持久/退回逻辑);前端 ≥3(拖拽排序状态/分组渲染);五门全绿;真机:97 条素材(拍摄时间是编码时刻,有自然断档)自动成章,拖两条换序后导出顺序改变。

纯写不碰 git 不跑构建;迁移只加 0010;禁碰 player 内部/sidecar。
