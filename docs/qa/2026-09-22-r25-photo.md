# R25 photo 车道报告 —— TC-0115-007 照片网格卡片尺寸不一致

worktree `tripcut-wt-r25-photo`,分支 `feat/r25-photo`,基线 main `4861f11`(v0.11.5)。

## 根因(已用代码 + 截图确认,不是猜测)

`PhotoGrid.tsx` 渲染卡片时没有 `.media-pool` 祖先类,而 `src/styles/workspace/pool.css`、
`src/styles/workspace/photo-r21.css` 里所有卡片尺寸/`object-fit`/角标定位规则都写成
`.media-pool .pool-card...` 选择器 —— 在照片工作台完全不生效。实际生效的是
`src/styles/workspace.css` 里未加限定的基础规则:`.pool-card-image { aspect-ratio: 16/9 }` +
`.pool-card-image img { object-fit: cover }`。叠加 `PhotoGrid.tsx` 里 `columns` 计算的
`Math.min(4, …)` 硬上限 —— 窗口变宽超过 4 列能容纳的宽度后,已有的 4 列被持续拉宽。
两者共同造成:照片一律被 16:9 裁切(与方向无关)、窗口变宽时卡片被异常拉宽、折叠后的单卡片
行在拉宽的网格里显得比例失衡。

## 接线人第一轮验收不通过,三处真实缺陷(本节新增)

接线人放大看了截图后指出:1)长文件名卡片(R25-6)缩略图/文件名溢出卡片外框、压到右边卡片;
2)建议段闪电角标(`.pool-card-bolt`)盖住分辨率角标;3)相似组动作行(「×n 展开 擂台」)压住
文件名。指出「断言只量了外框、没量内容是否溢出」——第一轮只加了 `aria-colcount`/宽度断言,没有
真正测过卡片内部元素是否溢出,这是本车道的检测盲区,不是接线人的误判。逐条根因(都是在真浏览器里
用 `getBoundingClientRect()` 量出来的,不是猜的):

1. **闪电角标盖资料**:R11 的 `HANDLERS.list_clips`(`fixture.ts` 既有代码)按 `id % 2 === 0`
   无条件把 `has_suggestions` 翻成 `true`;`?photos=1` 分支已经把它扭回 `false`(视频专属概念,
   照片不该有),但我加的 `?photostress=1` 分支只 `push` 了新夹具、没有比照 `?photos=1` 同样重新
   包一层 `list_clips`——偶数 ID 的压力照片被漏网,闪电角标(定位假设旁边是 5 字符时长
   `"12:34"`)贴着分辨率角标(`"7680×4320"` 宽得多)绘制,视觉重叠。
2. **长文件名溢出卡片**:`<button>`(`.pool-card`)在 `display:flex` 下仍走浏览器的
   shrink-to-fit 宽度算法,而 `.pool-card-name-line`(`fileNameLines` 切出的头/尾两段)在
   `workspace.css` 里从来没有非 `.media-pool` 版本的截断规则——`white-space: nowrap` 但没有
   `overflow`/`text-overflow`,长文件名把 `.pool-card` 自己的首选宽度撑到 275.75px(量出来的),
   比 160.7px 的网格单元宽,`.photo-ws-card-wrap` 没设 `overflow`,于是整张卡溢出到下一列。同一个
   shrink-to-fit 问题也解释了另一条独立现象——「时间未知」组的方形/竖图卡片量出来只有 139.9px,
   比同密度的横图卡片(160.7px)窄:固定 118px 高度下,窄高的图片本身对 shrink-to-fit 算法贡献的
   首选宽度更小,`.pool-card` 就跟着收窄。
3. **相似组动作行压文件名**:`.photo-ws-card-flags` 原来锚定卡片外框的 `bottom:6px`,但卡片底部
   是文件名+评分的固定信息区,不是图片——移到图片底部(向上 42px)又会压到同一个位置的分辨率角标;
   而 4 个动作 pill(「主图」「×n」「展开/收起」「擂台」全部同框时,如 R21 基线夹具「湖畔晨光.JPG」
   ——它既是相似组主图又带 RAW 伴随)量出来天然比卡片宽(~230px vs ~160px),放哪个角都会跟别的
   角标打架,因为四个角都已经有其它覆盖层占着(照片/RAW 徽标右上、RAW 伴随徽标左上、分辨率角标
   右下、建议段闪电角标左下)。
