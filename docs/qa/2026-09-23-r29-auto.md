## 3. 根因

### 3.1 素材属性不是原因(诊断包,每条 30 s,窗口在后台)

| 夹具 | hwdec | 像素格式 | gamma | 呈现 fps(均) | vo / 解码掉帧(稳态) |
|---|---|---|---|---|---|
| 4:2:0 无标记 50p | videotoolbox | p010 | bt.1886 | 48.9(=50,首末两个不满秒) | 1 / 0 |
| 4:2:0 HLG 50p | videotoolbox | p010 | hlg(色调映射开) | 49.0 | 2 / 0 |
| 4:2:0 PQ 50p | videotoolbox | p010 | pq(色调映射开) | 48.6 | 1 / 0 |
| 4:2:0 BT.709 50p | videotoolbox | p010 | bt.1886 | 48.9 | 1 / 0 |
| 4:2:2 无标记 50p | videotoolbox | **p210** | bt.1886 | 49.0 | 0 / 0 |
| 4:2:2 HLG 50p | videotoolbox | p210 | hlg | 48.7 | 1 / 0 |
| 4:2:0 HLG 60p | videotoolbox | p010 | hlg | 58.5 | 1 / 0 |
| 4:2:0 HLG 25p | videotoolbox | p010 | hlg | 24.3 | 1 / 0 |

- 没有软解回退,GL 互操作 p010 / p210 都成功,HDR 色调映射不拖帧率。每帧 render 调用 ≈ 帧间隔(`block_for_target_time` 等到目标时刻),flushBuffer 0.4–1.2 ms;交换间隔 = 1。
- **窗口置前可见**(业主空闲时,Retina ProMotion)4:2:0 HLG 50p:呈现 49.9–50.3 fps,20 s 掉帧 0,flushBuffer 0.4–2.4 ms。「50p 在 120 Hz 屏上被误计」证伪。
- 0.11.9 同条件(掉帧计数):0 / 10 / 1 / 2 / 0 / 5(均在开播与暂停瞬间),不降级。

### 3.2 真正的原因:监视器被盖住时 mpv 把每一帧都记成掉帧

- 监视器被任何 DOM 覆盖层(导入 / 交付抽屉、设置、命令面板、帮助、首页、引导气泡)盖住时原生视图不画(`hidden`),mpv 照常播;vo_libmpv 等不到渲染,200 ms 超时后把帧记成掉帧。诊断:遮挡期间呈现 **0 fps、vo 掉帧 50–61/秒**。
- R28 判据(6 s ≥30 帧且分散 ≥4 秒)必中。**0.11.9 真机**:
  - 播 4 s → 打开「导入素材」**5 s** → 关:`原片播放持续掉帧 total=111` → 换 540p → 关掉弹层后角标一直是 **「代理 540p · 原片掉帧,改播代理」**(= 业主「现在播放还是代理」「为啥说我原片掉帧」;暂停去抖后回原片 = 「暂停才是原片」)。
  - 盖 **12 s**:原片 → 540p(total=147)→「代理也持续掉帧」→ 回原片并本次锁死(total=292)。
- 第二个同类:窗口最小化 / 应用隐藏时 AppKit 把画帧节流到 **0.8–8 帧/秒**(fix1 真机偶遇:业主回来窗口被最小化,25p 夹具被判播不动)。同属「没人在看」。
- 退的是 540p(1080p 只在高画质档生成),所以糊。

## 4. 修复

- **R29-1 判据**(`drop_watch.rs` 重写):渲染线程真正画到屏上的帧按秒结桶,低于应有帧率(`container-fps`,封顶 60)的 90% 为坏秒;宽限 3 s 后最近 6 秒坏秒 ≥4 才算播不动。**不评判**:DOM 遮挡、窗口不在屏上(主线程每 0.5 s 查 `isMiniaturized` / `occlusionState`)、非 1 倍速、换源中。mpv 掉帧计数只留给角标 / 日志。「代理也播不动 → 回原片锁死」保留。原片档的「原片播放掉帧」提示在遮挡期间按暂停清零。
- **R29-2 退路**:有 1080p 用 1080p;没有则排队生成(每条素材本次会话一次,复用高画质档入队,抽成 `ensure_proxy_hq`),期间 540p,状态轮询发现 1080p 就绪即在播放中换上。角标「代理 1080p · 原片播放不动,暂用 1080p 预览」/「代理 540p · 原片播放不动,1080p 预览生成中」。设置自动档:「自动(推荐):看原片,播放不动才改播 1080p 代理」。
- **记忆**(`auto_memory.rs`,进程内):判过播不动的素材再打开开播直接用代理;锁回原片的决定也记住;换素材 / 重启重新判。
- **R29-0 诊断**:`TRIPCUT_PLAYER_DIAG=1` 每秒一行 `player diag`。GL 计时查询在 Apple Silicon GL 上恒为 0,已删,改抽样 glFinish。
