# 「旅剪工作台」v0.1 → v0.2 详细测试矩阵

结论：本轮完成静态只读审查，覆盖指定的 10 个前端组件、响应式样式、前端 IPC 映射及 [lib.rs](../../src-tauri/src/lib.rs) 的 50 个 Tauri commands。没有修改文件、运行应用、构建或测试。

以下“期望行为”是今晚自动化的验收口径，不代表当前实现已经通过。历史记录曾出现打包 App 的 `libmpv.2.dylib` 签名/加载崩溃；本轮未复核，可能已过时，因此打包启动与沉浸播放器必须作为第一个 P0 门禁。

## 0. 判定规则

- PASS：控件状态、后端副作用、重启后持久化三者一致。
- FAIL：按钮“看起来成功”但 command 失败、状态回滚不完整、重启丢失、输出包不可回读。
- BLOCKED：工具链、真素材、剪映或打包 App 不可用；必须记录具体缺失项，不能用静态测试代替。
- 每条用例保存：窗口尺寸、主题、素材 ID/文件名、触发 command、错误全文、截图/录屏、重启后的复核结果。

# 3. 20 条端到端链路

|---|---|---|---|

# 4. 首用者易用性审查点

## 会迷路

- 主导航是四步，帮助是五步；“打点”和“故事”没有一级入口。
- 首次进入筛片页默认选中第一条素材，但用户未必知道键盘评级作用于“当前选择”。
- Storyboard 藏在“筛片 → 故事板”切换中，交付页又直接成为下一主导航步骤。
- 多个过滤器可以叠加，但没有“清除全部过滤”；空结果只让用户逐项猜测。
- 搜索结果、胶片墙结果和 Stack 容器数是不同概念，当前文案没有解释。

## 反馈缺失

- 导入不能暂停/取消，也没有预计剩余时间、当前文件或工具链阻塞原因汇总。
- 播放器的 I/O/S 只有快捷键，没有鼠标按钮；首次用户很难发现“如何保存精选段”。
- 设置页大量项目“失焦即保存”，没有脏状态、显式应用按钮或失败回滚。
- 故事板拖拽缺少键盘替代，也缺少明确落点指示和跨章移动方式。
- L3 批量描述开始后没有取消按钮。
- 搜索命中卡片后没有稳定滚动/定位反馈。
- 缓存二次确认只靠页面顶部 notice；在长设置页中可能不在视区内。
- 第一轮工具链引导只是复制终端命令，没有解释如何打开终端、如何判断命令执行结束。

## 文案不清或不一致

- “P1 / P2”“D2 / D3 / L1 / L3”“Best Take”等内部术语面向普通用户过多。
- `Promote Hero` 与大部分中文 UI 不一致。
- 帮助称 R 为“永久排除”，实际 R 可以再次恢复为 auto。
- 交付页写“条收藏素材”“按整条素材计算”，但后端也会交付精选段并按段计算时长。
- 播放器错误写“已退出沉浸态”，但错误 Overlay 仍覆盖屏幕。
- “只看 Stack 首选”折叠后没有明确告诉用户隐藏了多少候选。
- L3 账本将未知 purpose 默认显示为“导演问答”，叙事编排会被误标。

# 5. 静态代码复核疑点

以下是源码疑点，必须通过用例复现后再定性。

## P0

1. 🔴 **筛片墙子按钮的 Enter 可能被父级快捷键劫持**

   - 位置：[SelectPage.tsx:551](../../src/SelectPage.tsx:551)、[SelectPage.tsx:1366](../../src/SelectPage.tsx:1366)

   - 建议：父级快捷键先排除 `button/input/select/textarea` 子目标，或只在 grid 自身拥有焦点时执行；为子按钮补键盘回归。

   - 位置：[PlayerOverlay.tsx:141](../../src/PlayerOverlay.tsx:141)、[player/mod.rs:198](../../src-tauri/src/player/mod.rs:198)、[lib.rs:829](../../src-tauri/src/lib.rs:829)
   - 问题：viewport 只在打开前计算一次；会话打开后 `set_viewport` 明确拒绝更新；窗口 resize 只 `request_redraw()`。
   - 建议：支持运行中安全调整原生 NSView frame，或 resize 时保存位置并重建 surface；必须覆盖 Retina、显示器切换和控制条高度。

# 4. 首用者易用性审查点

## 会迷路

- 主导航是四步，帮助是五步；“打点”和“故事”没有一级入口。
- 首次进入筛片页默认选中第一条素材，但用户未必知道键盘评级作用于“当前选择”。
- Storyboard 藏在“筛片 → 故事板”切换中，交付页又直接成为下一主导航步骤。
- 多个过滤器可以叠加，但没有“清除全部过滤”；空结果只让用户逐项猜测。
- 搜索结果、胶片墙结果和 Stack 容器数是不同概念，当前文案没有解释。

## 反馈缺失

- 导入不能暂停/取消，也没有预计剩余时间、当前文件或工具链阻塞原因汇总。
- 播放器的 I/O/S 只有快捷键，没有鼠标按钮；首次用户很难发现“如何保存精选段”。
- 设置页大量项目“失焦即保存”，没有脏状态、显式应用按钮或失败回滚。
- 故事板拖拽缺少键盘替代，也缺少明确落点指示和跨章移动方式。
- L3 批量描述开始后没有取消按钮。
- 搜索命中卡片后没有稳定滚动/定位反馈。
- 缓存二次确认只靠页面顶部 notice；在长设置页中可能不在视区内。
- 第一轮工具链引导只是复制终端命令，没有解释如何打开终端、如何判断命令执行结束。

## 文案不清或不一致

- “P1 / P2”“D2 / D3 / L1 / L3”“Best Take”等内部术语面向普通用户过多。
- `Promote Hero` 与大部分中文 UI 不一致。
- 帮助称 R 为“永久排除”，实际 R 可以再次恢复为 auto。
- 交付页写“条收藏素材”“按整条素材计算”，但后端也会交付精选段并按段计算时长。
- 播放器错误写“已退出沉浸态”，但错误 Overlay 仍覆盖屏幕。
- “只看 Stack 首选”折叠后没有明确告诉用户隐藏了多少候选。
- L3 账本将未知 purpose 默认显示为“导演问答”，叙事编排会被误标。

# 5. 静态代码复核疑点

以下是源码疑点，必须通过用例复现后再定性。

## P0

1. 🔴 **筛片墙子按钮的 Enter 可能被父级快捷键劫持**

   - 位置：[SelectPage.tsx:551](../../src/SelectPage.tsx:551)、[SelectPage.tsx:1366](../../src/SelectPage.tsx:1366)
   - 问题：整个 grid 接收冒泡的 `keydown`；在卡片、候选或“锁定/排除/Hero”按钮上按 Enter，父级可能把“当前旧选择”改为 locked，并阻止原按钮 click。
   - 建议：父级快捷键先排除 `button/input/select/textarea` 子目标，或只在 grid 自身拥有焦点时执行；为子按钮补键盘回归。

2. 🔴 **播放器窗口缩放只重绘，不更新原生 viewport**

   - 位置：[PlayerOverlay.tsx:141](../../src/PlayerOverlay.tsx:141)、[player/mod.rs:198](../../src-tauri/src/player/mod.rs:198)、[lib.rs:829](../../src-tauri/src/lib.rs:829)
   - 问题：viewport 只在打开前计算一次；会话打开后 `set_viewport` 明确拒绝更新；窗口 resize 只 `request_redraw()`。
   - 建议：支持运行中安全调整原生 NSView frame，或 resize 时保存位置并重建 surface；必须覆盖 Retina、显示器切换和控制条高度。

## P1

3. 🟡 **设置保存失败不回滚，界面可能显示未落库值**

   - 位置：[SettingsPage.tsx:299](../../src/SettingsPage.tsx:299)
   - 问题：先更新本地 state/主题，再调用 `set_setting`；失败只改 notice。开关、主题、路径可能呈现与数据库相反的状态。
   - 建议：保存前保留旧值；失败回滚并重新读取后端，或显示明确未保存状态。

4. 🟡 **拖动 Best Take 权重会对每个变化值执行全量重评分**

   - 位置：[SettingsPage.tsx:228](../../src/SettingsPage.tsx:228)、[lib.rs:91](../../src-tauri/src/lib.rs:91)
   - 问题：range 每次 `onChange` 都写设置，而每次权重写入都会同步 `rescore`。
   - 建议：拖动期间只本地预览，在 pointer-up/blur 提交一次；设置写入与重评分放在同一事务。

5. 🟡 **“0 清除评级”由两个独立 command 组成，不具原子性**

   - 位置：[SelectPage.tsx:1141](../../src/SelectPage.tsx:1141)
   - 问题：二元评级和星级通过 `Promise.all` 分别写入；其中一个成功、另一个失败会形成半清除状态。
   - 建议：新增后端原子 `clear_clip_rating`，单事务清除两类评级。

6. 🟡 **搜索命中与现有过滤器集合不一致**

   - 位置：[SelectPage.tsx:1041](../../src/SelectPage.tsx:1041)、[SelectPage.tsx:1116](../../src/SelectPage.tsx:1116)、[SelectPage.tsx:1751](../../src/SelectPage.tsx:1751)
   - 问题：命中列表展示原始搜索结果；点击时只清评级过滤和疑似废片，未清八维过滤。选中 ID 可能立即被“不可见选择修正”改成首个可见项。
   - 建议：命中列表也应用完整过滤器，或点击命中时清除全部冲突过滤并滚动定位。

7. 🟡 **Stack 卡片可能显示另一隐藏候选的匹配度**

   - 位置：[SelectPage.tsx:225](../../src/SelectPage.tsx:225)
   - 问题：卡片展示 representative 的封面，但语义分数取 Stack 所有成员最大值。
