## 3. 逐项处置

### Q1 1080p 高清代理 —— 完成
- 新任务 `proxy_hq`:短边 1080,`scale='if(gte(iw,ih),-2,1080)':'if(gte(iw,ih),1080,-2)'`(按**自动旋转后**的帧判横竖;Codex 初版按 `clips.width/height` 判,手机竖拍「编码 3840×2160 + 旋转 90」会被缩成 608×1080 —— 已改,本机 ffmpeg 实测横 1920×1080 / 竖 1080×1920 / 方 1080×1080)。码率 = 源码率夹 [4, 16] Mbps(省内存档 10)。产物 `<clip>/proxy_1080.mp4`,映射独立表 `proxy_hq_time_map`。
- **只按需生成**:「高画质」档打开素材时缺 HQ 才排一条(幂等);不进导入首轮;**旧 540p 缓存不删**。
- 迁移 0055:按 0005 套路重建 `cache_artifacts`(CHECK 加 `proxy_hq`,旧行逐列原样拷)+ 建 `proxy_hq_time_map`;无触发器/视图/外键引用该表(已 grep)。
- LRU 上限、按天清理、清缓存重建、任务资源类(Decode)一并认 `proxy_hq`,淘汰时连带删对应映射。
- 负责人修:`enqueue_proxy_hq_if_needed` 初版在 Immediate 写事务里调 `verified_clip_path`(外置盘要整文件哈希)→ 改为先无锁预查、锁外核验、锁内复查。
- 真机:HQ 产物 `h264 1920×1080 yuv420p 13.6 Mbps`(源 75 Mbps);540p 代理 `960×540 3.6 Mbps` 同时保留。

### Q2 取源策略 + 线程内换源 —— 完成
- `player/preview_source.rs`(新):`PreviewQuality` 四档、`SourcePlan`、`initial_kind`(按档位的可用来源优先序)、`auto_target`、`SourceSwitcher`。换源 = 同一 mpv 实例 `loadfile <path> replace -1 start=<该源映射秒>,pause=yes|no`:原生视图、LUT(`vf`)、监听轨(`aid`)、速度、静音、出点围栏(`end`)都是全局选项,跨 loadfile 保持;不闪 loading(换源期间屏蔽旧文件的 EndFile / time-pos / pause 事件,phase 保持 ready)。
- 自动档:暂停 **100 ms** 去抖(从 Pause 命令那一刻起算)后切原片同一时码;`Play` 命令先切回 540p 代理再开播;停在 EOF / 出点围栏(`eof-reached`)时不切。
- 负责人修的四处:
  1. **原片延后核验**:初版每次打开都 `verified_clip_path`(外置盘整文件哈希),且原片离线时连代理都打不开 —— 0.11.5 有代理时从不核验原片,这是回归。改为:只有当前档位此刻就要原片才核验;自动档打开后后台核验再补进计划;原片离线时任何档都退回代理(角标如实写「代理」)。
  2. **载入中的 seek / 逐帧**:mpv 在新文件初始化前拒绝 `seek` / `frame-step`,原样执行会让渲染线程报错退出 → 载入期间 SeekAbs 记下、PlaybackRestart 后补做,逐帧吞掉(并定为暂停意图)。加 3 s 看门狗。
  3. **P1(真机发现)渲染线程高频同步读属性卡死**:初版每轮循环(播放中 50 Hz)`mpv.get_property("eof-reached")`、掉帧变化时同步读两个计数。High 档真机一次 Pause 命令 2 s 无响应 →「播放器异常 / 播放器命令响应超时」。改为 `eof-reached` 与两个掉帧计数全部走 observe 事件、缓存在 switcher 里。修后 High / Auto 各 10 轮快速播停(2 s / 0.8 s)零异常。
  4. 去抖 150 → 100 ms 并从 Pause 命令起算(见 §4 数字)。
- `lib.rs`:`player_open` 用新计划选路径再调原 `player.open(...)`(签名与语义不变);新命令 `player_set_preview_quality`;`player_status` 在高画质档、HQ 未就绪时每秒至多一次后台查库,就绪即接上(真机:播放中 original → proxy_hq 145 ms,误差 0.02 s)。`resolve_playback_source` / `open` / `loadfile_args` / `execute_command` 函数体未改。
