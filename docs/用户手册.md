# 旅剪工作台 · 使用手册

> 面向长期旅行 / 房车 vlog 创作者的素材筛选工作台。
> 它站在剪映**之前**：帮你从几百条素材里挑出真正能用的，理好故事顺序，再交给剪映精剪。
>
> **原片永远只读。** 这个软件从不复制、不改写、不删除你的原始素材，只在自己的数据库里记录选择。

---

## 一、第一次使用

### 1. 安装

双击 DMG，把「旅剪工作台」拖进「应用程序」文件夹。首次打开如果 macOS 提示「无法验证开发者」，在「系统设置 → 隐私与安全性」里点「仍要打开」。

### 2. 安装向导

第一次启动会自动弹出向导，分两步：

**01 · 本机组件**

| 组件 | 作用 | 说明 |
|---|---|---|
| FFmpeg / FFprobe | 读取和处理视频 | 点「一键安装」自动下载（约 80 MB），**必装** |
| Whisper | 把对白转成文字 | 已随安装包附带，通常显示绿点 |
| 转写模型 | 转写用的语言模型 | 点「一键安装」下载（约 1.6 GB），想用对白搜索才需要 |
| 画面语义搜索 | 用文字搜画面内容 | 可选，想用「搜画面」功能才需要 |

绿点 = 已就绪，圈 = 未安装。没装齐也能用，只是对应功能不可用。

**02 · AI 助手（可选）**

如果你已经订阅了 Claude Code、Codex CLI 或 Kimi，点「打开终端登录」完成授权，就能用 AI 描述素材、智能编排故事。**没有订阅完全不影响核心功能。**

向导可以随时跳过，之后在「设置 → 帮助与关于 → 打开安装向导」重新打开。

## 二、基本工作流

软件左侧是四步流程，按顺序走：

```
01 导入  →  02 筛片  →  03 交付
                ↑
              04 设置
```

### 第 1 步：导入素材

点右上角「＋ 选择素材文件夹」，选中你的素材目录；也可以直接把文件夹或视频文件拖到导入页，松开即导入。

**软件只建立索引，不复制文件。** 导入后会自动分析每条素材（画面质量、运镜、场景切分等），进度条走完即可进入筛片。

**几个实用特性：**

- **子文件夹自动变分类**：如果你的素材是按「无人机 / 街拍 / 美食」这样分好文件夹的，文件夹名会自动成为素材分类，筛片时可以直接按分类过滤。
- **文件夹自动同步（适合 NAS / 云盘）**：选过的文件夹会进入「已关注」列表，软件每 5 分钟自动检查有没有新素材并自动导入。可以单独开关，也可以点「立即扫描」手动触发。NAS 没连上时会明确告诉你「目录不可用」，不会假装扫过了。
- **外置盘换了路径也能重连**：素材所在的移动硬盘或相机卡换了盘符、路径变了，导入页顶部会弹出「缺失素材」面板，按卷分组列出缺失的文件；点「选择新位置」后软件按内容哈希重新绑定，文件名相同但内容不同的文件会被拒绝并单独列出，不会误绑到错的文件上。
- **内存紧张时自动降速**：内存 24 GB 以下的机器会自动切换到省内存档，降低解码并发；导入过程中如果系统可用内存跌到过低，会暂停解码与模型任务并在导入页提示，恢复后自动继续。也可以在「设置 → 性能」手动选档位（自动 / 标准 / 省内存）。

### 第 2 步：筛片

这是你花时间最多的地方。

**看素材**：双击卡片或按空格键打开播放器。

**播放器快捷键**（中文输入法下也能用，不用切换）：

| 键 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `L` / `K` | 播放 / 暂停 |
| `J` | 回退一秒 |
| `←` `→` | 逐帧 |
| `I` / `O` | 设置入点 / 出点 |
| `S` | 保存精选段 |
| `Esc` | 返回筛片 |

**给素材做标记**（在胶片墙上选中卡片后按键）：

| 键 | 作用 |
|---|---|
| `F` | 收藏（这条要用） |
| `X` | 拒绝（这条不要） |
| `1`–`5` | 打星级 |
| `0` | 清除评级 |
| `Tab` | 展开 / 收起 Stack |
| `↑` `↓` | 在 Stack 候选间切换 |
| `L` / `R` | 锁定 / 排除 Stack 候选 |

**过滤工具条**：

- **全部 / 收藏 / 未评 / 拒绝**：按评级状态筛
- **📁 文件夹**：按你的子文件夹分类筛
- **八维筛选**：按运镜、景别、主体、视角、功能、人物状态、时间阶段、声音筛
- **排除普通疑似废片**：藏起画质有问题的（但人物镜头和信息镜头不会被藏）
- **只看 Stack 首选**：相似素材只显示 AI 推荐的那条
- **本集避免重复**：藏起以前的集数用过的素材
- **竖屏**：只看竖屏素材（按 rotation 与画面比例判定，包括拍摄时物理转了 90°/270° 但文件本身还是横向存储的素材）

**一键 AI 全读**（页头按钮）：给当前筛选结果里还没有描述的素材批量生成 AI 描述。已有描述的会自动跳过，不重复消耗额度。

**画面文字识别**：缩略图生成后软件会在本机自动跑一遍画面文字识别（离线运行，不联网，同时认中英文），把画面里出现的路牌、菜单、字幕之类的文字记下来。识别到的文字会显示在筛片右栏的「画面文字」角标里；如果识别工具没装好，这一项任务会显示「组件未安装」而不是卡住不动，且不影响其他分析任务照常跑完。

**全局搜索**：左侧搜索框或 `⌘K`，一次搜六类内容——文件名、对白转写、AI 描述、八维标签、画面文字、拼音。每条结果会标来源徽章（文件 / 转写 / AI / 标签 / 画面文字 / 拼音），点结果直接跳到那条素材。

**拼音搜索**：输入两个及以上英文字母（比如 `lvpai` 或首字母 `lp`）也能命中文件名、标签、章节标题里的中文「旅拍」——不用切换输入法就能用拼音代替中文打字；纯中文查询和太短的输入不会走这条路径。

**历史集命中是只读的**：搜到的素材如果属于已封存的历史集，点结果会打开该集的只读历史视图，而不是切换当前集的过滤器；当前集的筛选状态不会被打断。

**相似镜头**：右栏的「相似镜头」面板可以查看同组的相似素材，点「设为主镜头」把某条设为该组的代表；历史集为只读档案，回到当前集才能切换。

**技术检查**：右栏还有「技术检查」面板，一眼看清这条素材的拍摄参数：

- **分辨率 / 实际帧率 / 编码**：实际帧率会标出可变帧率（VFR）；
- **方向**：横屏 / 竖屏 + 旋转角度；
- **色彩**：转移函数文本，检测到 D-Log 或 HDR 会额外加徽章；
- **ISO / 快门 / 光圈**：设备没记录的字段显示「设备未提供」，不是空白也不是猜测值；
- **音轨列表**：列出这条素材的每一路音轨，标有角色猜测（机内麦克风 / 无线麦克风 / 备份轨 / 未知）；可以逐条点「监听」切换预览听哪一路，点「设为转录轨」指定转写用哪一路；
- **显示 LUT**：下拉选一个 `.cube` 文件，播放器按它预览色彩。**LUT 只影响预览，不会写进导出的文件**；LUT 文件要手动放进应用支持目录下的 `luts/` 文件夹。

**多声道音轨**：导入时会记录素材的全部音轨并做角色猜测；转写默认用你选定的那一路（没选过就用第 0 路）。生成剪映草稿时，探测到多轨的素材，素材名后面会追加音轨映射，例如「`clip.mov [音轨映射 0=机内麦(转录)/1=无线麦]`」，交付说明.txt 也会有一句同样的映射说明，方便核对转写字幕对应的是哪一路麦。

> R3 之前导入的旧素材没有音轨记录，需要在技术检查面板里手动点一次「探测音轨」才会补上音轨列表和 ISO / 快门 / 光圈；新导入的素材会自动记录，无需手动操作。

**删错了可以撤销**：保存精选段后按「删除」，10 秒内界面上会出现「撤销」按钮，点一下即可恢复被删的精选段。超过 10 秒后按钮消失，需要重新框选。

### 第 3 步：交付

点「生成交付包」，选保存位置，得到一个可以直接拖进剪映的文件夹：

```
旅剪项目_剪映交付_2026-09-03/
├── 01_精选原片/            按推荐顺序编号的素材
├── 02_环境声与旁白/旁白稿.txt  按叙事分章生成的旁白草稿，可直接改写后配音——已确认的修订写入后标注“已确认”；叙事修订尚未人工确认时，也会按 AI 建议写入草稿，但文件头会标注“（AI 建议稿，未经人工确认）”，需人工核实后再配音
├── 03_字幕/                与素材同序号的 SRT 字幕
├── 04_参考粗剪/参考粗剪.mp4 串好的参考视频，可直接预览故事顺序
├── 05_镜头表/剪辑清单.csv   每条素材的包内路径、参数、星级、对白摘要、平台、画布、转录音轨
├── 05_镜头表/联系表.pdf    A4 网格联系表(勾选「联系表.pdf」才会生成)
├── 06_LUT与色彩说明/       色彩说明(后续版本)
├── 07_地点卡/              目的地信息卡
└── 交付说明.txt            怎么导入剪映的步骤说明
```

交付页有一个默认勾选的「联系表.pdf」选项：一份 A4 网格联系表，每张卡片是封面缩略图 + 序号/文件名、入出点、章节标题三行文字，横屏这一集排 4 列、竖屏排 3 列（跟着这次交付的画布方向走）。联系表内嵌了中文字体，极个别生僻字如果字体里没有会显示成「□」，交付说明.txt 会写明具体缺了几个字，不会不声不响地漏字。不需要联系表可以在交付页取消勾选。

交付说明.txt 会写明本次的目标平台、画布尺寸和建议时长，例如「目标平台：抖音（竖屏 1080×1920，建议时长 ≤ 60 s）」；如果有素材探测到 2 路以上音轨，还会追加一句音轨映射，最多列 3 条素材，其余的折成「等 N 条」。

交付页有一个「参考粗剪时长」下拉：**完整 / 30 秒 / 60 秒 / 3 分钟**。选一个时长档位后，参考粗剪会按 Beat 顺序在预算内截取，不是简单裁前几分钟；如果目标平台设了时长预算（比如抖音的建议时长），下拉会自动预选一个不超预算的最大档位，没有任何档位能塞进预算时会回退到「完整」。

也可以点「生成剪映草稿」直接在剪映里创建草稿（需要装剪映专业版）；草稿的画布尺寸按这一集（或本次覆盖）的平台预设生成，不再固定按第一条素材的分辨率。

## 三、房车 / 长期旅行专属功能

### 集（Episode）

左侧栏顶部是「当前集」。周更创作者的工作循环：

1. 这一集的素材导入、筛选、交付
2. 点「封存本集」→ 弹出确认对话框，可以顺手为**下一集**选目标平台与画布方向（默认沿用当前集的设置），再次点击确认后本集变成只读档案，按你选的设置自动开启下一集
3. 下一集导入新素材，之前用过的镜头会有「已用×N」标记提醒你别重复

点集列表里的历史集可以只读查看（不能改，防止误改已交付的决策）。

「重命名本集」表单新增两项：**目标平台**（抖音 / 小红书 / B站 / 朋友圈 / 家庭纪录 / 通用）与**画布方向**（横屏 / 竖屏 / 同时）。标题旁的徽章会显示当前设置，比如「抖音 · 竖屏」，随时能看出这一集是按什么规格剪的。交付页另有一个「本次交付平台」下拉，可以临时用别的平台规格导出这一次，不会改动集本身的设置。

### 故事板（筛片页顶部切「故事板」）

AI 编排后，故事板按 Episode / Chapter / Beat 三级组织你的素材。**AI 给的是建议版，你的修改会存成确认版**，交付按确认版走：

- 章节标题：双击改
- 章节类型：下拉选（目的地 / 在途 / 房车生活 / 人物互动 / 意外事件……）
- Beat 角色：点 BEAT 徽章循环切换（Beat / Montage / Transition）
- Beat 顺序：直接拖拽，可跨章节
- 每步都能撤销（工具条「撤销编排编辑」）

**右侧五个页签**：候选 / 地点卡 / DH 计划（数字人节奏规划）/ 音乐与节奏 / 旅程时间线。

### 故事模板

点「一键 AI 编排」之前，可以先在故事板顶部选一张模板卡：**电影感 / 快节奏 / 安静氛围 / 旅行日记**，或者「不使用模板」（相当于按旅行日记规则走）。四张卡的编排逻辑不一样——电影感偏好缓慢运镜和空镜开场，快节奏优先短镜头和高密度剪辑，安静氛围偏好无人物的静止空镜，旅行日记严格按拍摄时间顺序、不重排。

**没有订阅 AI 助手也能编排**：这时软件会按你选的模板规则直接生成一版确定性的编排（不调用任何 AI），章节说明会写明「未启用 AI，按『模板名』模板规则生成」，让你清楚这一版是规则算出来的，不是 AI 判断的。装了 AI 助手之后重新编排，AI 版会覆盖建议版，但你已经确认过的内容不受影响。

### 音乐与节奏

故事板右侧「音乐与节奏」页签，用来给这一集配一条参考音乐、看节拍和段落，方便卡点：

- **导入音乐**：点「导入音乐」选一个本地音频文件。**软件只记录文件的绝对路径，不会复制这份文件**；如果之后把这个文件移动或删除了，软件会在列表里提示这条音乐找不到了，而不是假装还在。
- **分析结果**：导入后自动在后台分析 BPM、节拍点和段落（前奏 / 主歌 / 推进 / 高潮 / 尾声 / 其他），分析中每 3 秒自动刷新一次状态，不用手动重新打开。
- **切点建议**：波形条上的竖线是建议的卡点位置，点一下会把这个时间点复制到提示条里——**只是建议、不会强制**，也不会改动任何已经设置好的入点或出点。
- **没有明显节拍的曲目**：环境音、纯氛围类音乐分析不出节拍会被标为「分析失败」，可以换一首更适合卡点的曲子。
- 历史集为只读档案，这个页签也不能导入或删除音乐，只能查看已有的分析结果。

### 旅程时间线

故事板右侧「旅程时间线」页签，把这一集的素材按标准化的拍摄时间（跨设备校正过的 Canonical Journey Time）重新排成一条时间线，按天分组，每张卡片是地点信息 + 缩略图；没有时间信息的素材归到「未标时间」一组。**这个页签只读**，用来快速核对故事顺序是否符合真实的旅行顺序，不能在这里拖拽或编辑，要调整顺序请回到故事板主视图。

### Routine 重复行为处理

房车素材里大量是重复的日常（开车、扎营、做饭）。AI 会标出这些并给降级建议：

- **「全部接受降级」**：一键把所有建议落实
- **点单条 Routine 标签**：循环切换处理方式（完整解释 / 主故事事件 / 压成 Montage / 压成过场 / 普通 Beat / 整条保留 / 非 Routine 豁免）

**你的判断永远优先于 AI。**

## 四、素材质量判断说明

软件会给素材打这些角标，帮你快速排除废片：

| 角标 | 含义 | 判断依据 |
|---|---|---|
| **过曝** | 大片高光死白 | 90 百分位亮度触白位 **且** 整体偏亮。单个高光点（天空、路灯、反光）不算过曝 |
| **欠曝** | 画面过暗 | 10 百分位贴近黑位且整体偏暗 |
| **虚焦** | 对焦失败 | 模糊度高 **且** 画面基本静止 **且** 有足够纹理。运动模糊和纯色画面不会误判 |
| **手持抖动** | 手抖明显 | 相机运动轨迹的高频能量占比。平稳摇镜不会被判抖动 |
| **静音** | 没有音轨或几乎无声 | — |
| **已用×N** | 以前的集数用过 | 跨集记忆 |
| **VFR** | 可变帧率素材 | 属性说明，不是问题；时间映射已正确处理 |

**角标只作筛选辅助，永远不会自动删除或隐藏你的素材**（除非你自己打开了「排除疑似废片」开关，而且人物镜头和信息镜头始终豁免）。

### 分析算法更新后会怎样

软件升级如果改进了分析算法，**下次启动时会自动重新分析已导入的素材**，你不需要做任何事。重算在后台进行，不影响使用。

## 五、设置

| 分区 | 内容 |
|---|---|
| **外观** | 浅色 / 深色 / 跟随系统；界面缩放 90% – 130% |
| **性能** | 后台并发数、是否生成 540p 代理文件、内存档位（自动 / 标准 / 省内存，自动档在 24 GB 以下内存的机器上走省内存） |
| **旅行时间** | 多设备时钟校正（相机时间对不齐时用） |
| **工具链** | FFmpeg / Whisper 路径与状态，可手动指定；每个组件如果存在上一版本，会出现「回滚到上一版」按钮，装了新版本发现有问题可以一键退回 |
| **分析与 AI** | 场景阈值、抖动阈值、Best Take 权重、AI 预算上限与隐私说明 |
| **隐私与诊断** | 列出确切留在本机的内容、诊断日志目录入口；崩溃报告由 macOS 系统设置的「隐私与安全性 › 分析与改进」控制，软件本身不内置崩溃上报 |
| **帮助与关于** | 中文指南、安装向导、版本信息、「检查更新」 |

**检查更新**：设置页「帮助与关于」有个「检查更新」按钮，**软件不会自动检查**，只在你点击时才联网查一次。有新版本会显示版本号和更新说明，点「下载并安装」下载并验证签名（签名对不上会拒绝安装并提示「更新包签名校验失败」，不会替换现有程序）；安装完成后点「立即重启」应用新版本，你的项目数据不受影响。

**系统通知**：交付包生成完成、批量 AI 分析完成时，即使你切到了别的应用也会收到一条 macOS 系统通知；如果电脑睡眠期间有任务正在跑，唤醒后软件会自动接着跑完，不需要手动重试。

**AI 隐私**：AI 描述只发送文件名、时长尺寸、质量数值和运镜数值；导演问答只发送统计摘要和你的问题。**从不发送画面、视频、音频、绝对路径或 GPS。**

## 六、常见问题

**Q：提示「未检测到 FFmpeg」，但我装过了？**
从访达启动的应用拿不到终端的环境变量。用安装向导里的「一键安装」最省事，或者在「设置 → 工具链」里填写完整路径。

**Q：搜索英文文件名时中文输入法弹候选？**
先切到英文输入法（`Ctrl + 空格`）。搜中文内容（对白、AI 描述、标签）不受影响；如果你想找的是中文文件名/标签，也可以不切输入法，直接用拼音或首字母（两个字母以上）搜，比如打 `lvpai` 或 `lp` 能命中「旅拍」。

**Q：打开时提示「检测到另一个实例」？**
同时只能开一个窗口写数据。第二个窗口是只读的，关掉它回到第一个即可。

**Q：素材从一个文件夹移到另一个，会重复导入吗？**
不会。软件会识别出这是移动，自动更新路径和分类标签。

**Q：想让 AI 重新编排，会覆盖我改过的内容吗？**
不会。AI 重跑只更新「建议版」，你的「确认版」始终保留，交付按确认版走。

**Q：封存了一集，之前的素材还在吗？**
在。历史集是只读档案，随时可以在集列表里查看，只是不能修改（防止误改已交付的决策）。

**Q：旧素材的技术检查面板为什么没有音轨和 ISO / 快门 / 光圈？**
R3 之前导入的素材没有做过音轨与拍摄参数解析。在技术检查面板里点一次「探测音轨」就会补上；新导入的素材会自动记录，不用手动操作。

## 七、数据在哪

```
~/Library/Application Support/TripCutStudio/
├── default/
│   ├── project.db        项目数据库（评级、精选、编排、画面文字识别结果、音乐分析结果）
│   ├── snapshots/        自动快照（异常时可恢复）
│   ├── cache/            缩略图、波形、代理文件（可安全删除，会重建）
│   └── logs/             诊断日志（保留 7 天）
├── models/               转写模型
└── bin/                  向导下载的工具
```

**你的原始素材不在这里**，软件只记录它们的路径。删除缓存不会影响任何素材和你的选择。

**画面文字**（`clip_ocr_texts` 表）识别出的文字只存在项目数据库里，识别在本机离线完成，不上传画面或截图。**音乐文件**（`music_tracks` 表）同样只记录你导入时选中文件的绝对路径，软件不会把音乐文件复制进项目目录。
