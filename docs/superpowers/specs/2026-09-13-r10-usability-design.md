# R10 易用性修复与风险控制方案（0.4.0）

依据:`.superpowers/sdd/r10/usability-walkthrough.md`(2026-09-13 真机走查,37 条 U-NN)+ 控制端读码定位。
目标:让「首次用户按帮助页说的做,就能把一趟旅拍变成交付包」这条主线在真机上走通;
不改数据模型语义,不删旧界面(见 §4)。

## 1. 已定位根因(走查里的 P1)

| 编号 | 现象 | 根因(读码) | 修法 |

## 2. 其余修复(按走查编号,分五条车道)

**车道 A · 媒体池与键盘**:U-01、U-02(前端展开入口)、U-06(空库文案 + 大号「导入素材」入口,「筛选为空」与「库为空」分开)、U-15(池内搜索并入文件名;输入为空即复原)、U-26(Take 条尾计数「还有 n 条」+ 缩略图)。

**车道 B · Rust 核心**:U-02(分组键)、U-05(预设 + 迁移 0042)、U-13(方向 = rotation + 宽高比综合;VFR 阈值复核)、U-16(集计数实时;新建集命令)、U-19(音乐分析完成事件 → 前端刷新;状态条纳入)、U-22(首启引导「已跳过」持久化,只在真正首次出现)、U-24(Whisper 模型:官方地址 + 期望 SHA-256 + 「导入模型文件…」命令)。

**车道 C · 监视器**:U-09(可拖 seek bar;播到尾再按播放从头)、U-10(工具条最小宽度不溢出:时间码短格式、状态文字折行、全屏按钮不裁)、U-37(各栏 focus-visible 焦点环)。

**车道 D · 检查器与镜头带**:U-03、U-11(检查器「精选段」区:列表/复播/删除;自动收藏在提示里写明)、U-12(标签编辑与章节/槽位归属常驻——空态也显示「添加」,不再整段隐藏)、U-17(空章节算缺口;空槽位有「生成候选」/「从媒体池选择」按钮;禁用原因做成「去设置」链接)、U-18(卡片与检查器加「加入当前章节」按钮——不靠拖拽的第二条路;拖拽时落点高亮)、U-27(加载中要有终态)、U-28(LUT 导入入口)、U-29/U-30(章节名与缺口说明可读)、U-31(命名统一为「地点卡」;⌘K 默认高亮首项)、U-32(改名表单换设计系统)。

**车道 E · 壳、抽屉、设置、恢复页**:U-04、U-07(「选择中…/扫描中…」分开;添加后立刻刷新关注列表;路径中间省略)、U-08(任务页三段式进度;内部状态码不直出)、U-14(未启用时按钮禁用 + 「去设置」)、U-20(抽屉记住上次选择;文件夹名 `<集名>_交付_<日期>`;底部按钮「开始生成」)、U-21(缩放落到根字号)、U-23(选中与 Stack 首选持久化;恢复页之后不叠首启弹窗)、U-25(通知权限在首次后台任务统一申请)、U-33/U-34/U-35(文案)、U-36(恢复页换设计系统:标题自适应、主按钮首屏可见)。

## 3. 需要真机复核的两项

- **拖拽**(U-18):合成事件在 WKWebView 里触发不了 HTML5 DnD,车道 D 做完「加入当前章节」后,拖拽本身由业主真手复核;失败也不阻塞主线(已有第二条路)。
- **单键快捷键**(U-01):修完后由控制端用真机 AX 焦点 + `keystroke` 复核;`?` 能触发说明通道通,失败即是目标判定。

## 4. 风险控制

1. **不删旧界面**:原 R10 计划里的「删 `ui.workspace_v2` 旗标与旧壳」推迟到 0.4.0 被业主验收之后(R11)。0.4.0 期间「切回旧界面」仍是逃生口。
2. **数据零破坏**:唯一迁移 0042 只对 `platform_presets` 加列并回填;`shot_stack::rebuild` 改键后必须保留用户已设的 hero/拒绝状态(按 clip_id 迁移到新栈,写回归测试);不改 clips/segments/chapters。
3. **原生层零改动**:本轮不碰 `player/mod.rs`;seek bar 只走现有 `player_seek` 命令。任何触到 PlayerOverlay 视口提交的改动都要真机复核。
4. **每车道独立 CSS 与文件**,@import 在文件头;文件 <400 行;AX 名冻结(新按钮用新名);jsx-a11y 零。
5. **门禁**:fast-gates PASS 才推;真机烟测(缩放风暴 + 弹层 + 旅程 + 1280)每次合并后重跑;走查脚本(`.superpowers/sdd/r10/walkthrough` 的操作序列)在 0.4.0 候选上重跑一遍,逐条对照 U-NN 关闭。
6. **发布节奏**:0.4.0 先只打 QA DMG 到桌面给业主;公开 release 与更新源要等业主一句「发」。0.3.0 release 保留,随时可回退(应用内更新只会前进,回退用 DMG)。
7. **不做的**:云端补镜真实调用(无 key)、Developer ID、拖拽引擎替换、深色主题专项。
