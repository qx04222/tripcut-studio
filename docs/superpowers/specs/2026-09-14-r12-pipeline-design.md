# R12 「一条流水线」升级方案(0.6.0)

业主原则(2026-09-13/14):**易用 ≠ 什么都没有**。不是把东西藏起来让人找不到,而是让新手一眼知道
「这是一条流水线,我在第几步,下一步做什么」。功能都在,按流水线组织;每一步只有一个显眼的下一步。

依据:`.superpowers/sdd/r11/verify-v1.md` §B-列表(术语、主操作不明显、被迫进设置)、`verify-v2.md`、R11 规格 §6、
R10/R11 QA 报告里的决策项。

## 0. 流水线定义(整个 0.6 的骨架)

| 步 | 名称 | 用户要做的 | 「完成」的定义 | 界面焦点 |
|---|---|---|---|---|
| ① | 导入 | 选一个装视频的文件夹 | 素材 ≥1 且分析完成 | 导入抽屉 → 媒体池 |
| ② | 挑选 | 收藏/打星,或一键自动挑选;看建议段按 Enter | 精选段 ≥1 | 媒体池 + 监视器 |
| ③ | 排列 | 把挑出的片段按章节顺序排好,补缺口 | 每章 ≥1 镜(或用户点「就这样」) | 镜头带 |
| ④ | 导出 | 一键导出片段(或完整交付包 / 剪映草稿) | 至少导出过一次 | 导出抽屉 |

流水线状态由数据推导(不靠用户点「完成」),存 `pipeline.step_done.*` 只做「用户已看过第 n 步提示」。

## 1. 流水线导航条(车道 A · 壳)

- 顶栏中央的集切换器右侧改为**四步导航**:`① 导入 21 条 → ② 挑选 4 段 → ③ 排列 0/2 章 → ④ 导出`;当前步高亮,已完成步打勾,未开始步灰;每步可点击,点击 = 把界面焦点带到该步(打开抽屉 / 聚焦媒体池 / 聚焦镜头带 / 打开导出抽屉)。1280 宽以下只显示数字与勾。
- 顶栏右侧的主按钮改为**「下一步:…」**,文案随流水线变化:「下一步:导入素材」「下一步:自动挑选」「下一步:排到镜头带」「下一步:导出」;完成 ④ 后变「再导出一次」。原「生成交付包」按钮并入导出抽屉(「完整交付包」模式),AX 名「生成交付包」迁移为「下一步」按钮的固定 AX 名「流水线下一步」(冻结名解冻,迁移断言)。
- 每个栏的空态按当前步说话:媒体池空 = 「第 ① 步:先导入」;有素材但 0 段 = 「第 ② 步:按 F 收藏或点自动挑选」;镜头带空 = 「第 ③ 步:把挑好的片段排进来」并给「一键排入」按钮;导出抽屉顶部一句「第 ④ 步」。
- 首启:去掉工具链弹窗(工具链检查只在 ffmpeg/ffprobe 缺失时以横幅出现,主按钮「开始使用」);「三步卡」升级为「四步卡」,与导航条同一套数据。
- `?` 帮助页改为「流水线手册」:四步各 3 行「怎么做」+ 该步快捷键;每步首次进入时在导航条下方出一条可关的提示(`pipeline.hint_seen.n`)。

## 2. 挑选 → 排列 联动(车道 B · 镜头带)

- 现状缺口:自动挑选/手动保存的精选段**不进镜头带**(verify-v1 B-列表),第 ③ 步等于空转。改为:精选段创建即成为镜头带候选镜;镜头带「一键排入」把本集所有精选段按章节(有章按章、无章按拍摄时间)排成 story_order;自动挑选完成后默认已排入(toast 里可「撤销」)。
- 缺口卡只留一个主动作:有可用候选 → 「从挑好的片段里选」;没有 → 「回到第 ② 步挑几条」;云端补镜作为次级链接(未启用不显示按钮,只在「···」里)。
- 镜头带镜块可拖动排序(已有 dnd),并加「上移/下移」按钮(不靠拖拽的第二条路,新手友好)。
- 「就这样」:每章可点「这章够了」把 0 镜章标记为跳过(不算缺口)。

## 3. 反馈系统(车道 B)

- 新 kit `Toast`(顶部居中、3–5 s、最多 1 条、可带 1 个动作):自动挑选结果、撤销、导出完成/失败、排入完成都走它;替代镜头带底部 12 px 小字。
- 导出失败:toast「6 个导好了,3 个没导出来 · 只重试这 3 个」;失败原因一句人话。
- 状态条:「正在分析 12/21,大约还要 30 秒」(按最近速率估),完成后「分析完成 · 21 条」3 s 后收起。

## 4. 术语清扫 v2 + AX 改名(车道 C)

- B-列表逐条:首启弹窗(改为设置内「工具与模型」卡,用「转写(可选)」「画面识别(可选)」)、导出失败文案、完整交付包(「原画质导出」「竖版 1080×1920」「镜头表(表格)」,去掉 BOM/码率/画布)、技术检查(「画面 1920×1080 · 30 帧/秒 · 竖屏」,相机参数无则整段不显示)、设置性能(「后台同时处理几条」「预览用小文件」)、工具链(「视频处理组件 已就绪」,版本号收进「详情」)、分析与 AI(「分析严格程度」,删掉代理/启发式字样)、关于(「更新包已校验」)。
- 冻结的术语 AX 名改名并迁移断言:`Take n · 文件名` → `第 n 条 · 文件名`,「八维评分」→「画面评分」,「音轨与 LUT」→「声音与调色」,「Stack」相关 → 「同一镜头」;更新 `docs/design/design-system.md` 冻结表与 `axNames.test`/smoke 锚点。
- 新增门禁:`terminology.test` 扩展到 B-列表全部词。

## 5. 播放器行为与真变速(车道 D · 播放器 + Rust)

- 点卡片 = **预览**:选中并显示首帧/最精彩帧,不自动开播;空格/点播放才播;「连播」作为监视器上的显式开关(默认关),开了才播完自动下一条。(改 R11 的默认:自动巡播让新手「选中乱跑」,verify-v1 4a/V-05。)
- 原生 `set_speed`:`player/mod.rs` 新增 `SetSpeed(f64)`(mpv `speed` 属性,0.25–4×),`player_set_speed` 命令;L/J/K 与「×1」按钮改真变速,J 反向用 mpv `speed` 负值不支持 → 反向仍用 step 回退但按帧走。**触及原生层,必须真机跑缩放风暴 + 变速 + 弹层三合一烟测。**
- `,`/`.` 逐帧用 mpv `frame-step`/`frame-back-step` 命令(已有 step?若无则加)。

## 6. 导出步(车道 A)

- 导出抽屉顶部「第 ④ 步」一句话;模式:「导出片段」(默认)/「完整交付包」/「剪映草稿」三枚 chip,剪映不可用时 chip 带「(待验证)」并一句白话说明;「也顺便…」勾选(联系表 PDF、镜头表)。
- 完成后 toast + 「在 Finder 中显示」;失败可只重试失败项。

## 7. 风险控制

1. 无新迁移;精选段→镜头带联动只写既有 `story_order`,可撤销。
2. 原生 `set_speed` 是本轮唯一的原生改动,单独提交、单独真机烟测,失败可整段回退不影响其它车道。
3. AX 改名集中在车道 C 一次做完并同步 smoke/axNames/design-system,避免分散改名造成探针失明。
4. 每车道独立 CSS/文件;公共文件追加;门禁同前;合并后跑「新手脚本」真机验收(§8)。
5. 0.6.0 先 QA DMG 到桌面;公开发布等业主。

## 8. 验收:「新手 10 分钟脚本」

真机、全新库、不看文档:启动 → 看到四步导航 → 点「下一步:导入素材」选文件夹 → 等分析(状态条有预计时间)→ 点「下一步:自动挑选」→ toast 告知挑了几段并已排入 → 镜头带看到镜块,拖一下顺序或点上移 → 点「下一步:导出」→ 文件夹里有片段 → toast「在 Finder 中显示」。全程不进设置、不遇到术语、每一步都知道下一步点哪里;计时 ≤10 分钟(不含分析等待)。加 R9 稳定性烟测 + 变速烟测。
