# R13 向剪映对齐:布局、键位、设置、引导(0.7.0)

业主方向(2026-09-14):整体思路、UI 与使用方案参考剪映,让剪映用户上手难度极低;着重参考剪映的
设置;软件风格要启发式、引导式。
控制端判断:**借心智模型、引导方式、术语与键位,不借编辑器本体**。TripCut 是「筛选与整理,交给剪映」;
不做时间线级剪辑(裁切/转场/字幕/调色),不抄剪映的图标与视觉资产。

本机证据(只读看过业主的剪映配置):`commonSetting.ini` 里 20+ 个 `*_guide_viewed`/`*_guide_show_count`
开关 → 剪映的易用 = 逐功能一次性气泡引导;`Shortcut/` 下「剪映 / Premiere Pro / Final Cut Pro X / 自定义」四套
键位预设;全局设置只有几块(草稿位置、缓存、代理、快捷键、性能、语言)。

## 1. 键位预设(车道 A)

- 设置 → 「快捷键」分区(剪映同名):预设下拉「剪映(默认)/ Premiere Pro / Final Cut Pro / 自定义」;
  键位表按动作列出(播放/暂停、入点、出点、上一条/下一条、逐帧、收藏、拒绝、打星、分割前后(我们无 → 灰)、撤销/重做、全屏、导出…),
  每行可改;冲突即时提示;「恢复默认」。
- 默认改成**剪映键位**:空格播放、I/O 入出点、← → 逐帧、⇧← → 前后 5 s、J/K/L、⌘Z/⇧⌘Z 撤销重做、⌘E 导出、
  F 收藏、X 拒绝、1–5 打星、Enter 采用建议、N/⇧N 建议切换、Q/W 保留给「分割」(灰,说明「到剪映里做」)。
- 实现:`src/workspace/keymap.ts`(动作 → 键的表,预设 3 份 JSON),`useGlobalHotkeys`/`useMonitorHotkeys`/`useRatingHotkeys`
  改为查表;帮助页/工具条 `Kbd` 提示随预设变化;设置键 `keymap.preset` + `keymap.custom`(白名单)。

## 2. 设置对齐剪映(车道 A)

- 分区名与顺序改为剪映式:「项目与缓存」(项目库位置、缓存大小/清理、预览用小文件)、「快捷键」、「播放与导出」(从最精彩处开播、连播、导出文件夹、默认平台)、「性能」(后台并发、硬件加速开关若有)、「工具与模型」(可选组件)、「关于」。
- 每个分区顶部一句话说明「这里管什么」;所有项都是一行一控件,不再有「高级…」折叠(R12 原则:不藏)。

## 3. 剪映式引导(车道 B)

- 新机制 `guides.ts`:功能气泡 `Guide`(kit,锚到目标元素,一段话 + 「知道了」+ 可选「试试」动作),每个 guide 一个键 `guide.<id>.viewed`(白名单前缀 `guide.`),只弹一次;可在设置「关于」里「重置新手引导」。
- 首批 guide(各弹一次):导航条(第一次进入)、热力条(第一次选中有建议的素材)、自动挑选按钮(第一次进入第 ② 步)、镜头带镜块(第一次排入后:「拖动或用上移/下移调顺序」)、缺口卡(第一次出现)、导出抽屉(第一次打开)、连播开关(第一次播完)。
- 首页(空库或点顶栏 logo):剪映式「开始一个新旅程」大按钮 + 「最近的集」卡片列表(缩略图/集名/步骤进度)+ 三个模板卡(旅行日记 / 电影感 / 快节奏,点击 = 新建集并预选模板)。R12 的四步卡并入首页顶部。

## 4. 镜头带更像时间线(车道 C)

- 顶部时间刻度(按总时长自适应刻度);播放头(红线)与监视器联动:播放时沿镜块前进、点击刻度 seek 到对应镜块与时刻;
  镜块显示时长与缩略图,拖拽重排(已有)+ 拖边裁入出点(只改我们自己的精选段,不动原片);章节作为轨道分组(章名在左侧轨头,可折叠)。
- 不做:多轨、转场、字幕、调色;这些在导出步引导去剪映。
- 「导出到剪映继续剪」在镜头带右上常驻(可用时 primary,不可用时带「(待验证)」说明)。

## 5. 交接感(车道 C)

- 导出抽屉三模式顺序改为「剪映草稿 / 导出片段 / 完整交付包」,剪映可用时默认剪映;文案「导入剪映继续剪」;
  完成后 toast「已生成剪映草稿 · 打开剪映」(打开剪映草稿目录或直接 `open -a` 剪映)。
- 主题:新增「剪映风格深色」主题(可选,不默认);token 换一套深色值即可(R9 令牌化已支持)。

## 6. 风险控制

- 无迁移;键位/引导/主题全在 settings 白名单键;镜头带联动只走既有 `player_*` 与 `story_order`。
- 剪映草稿默认推荐仍以 11.4 白名单为闸(业主人工验证前不默认);不抄剪映图标/资源;不动 `player/mod.rs`。
- 每车道独立文件/CSS;门禁 + 真机「剪映用户 5 分钟脚本」(§7)。

## 7. 验收:「剪映用户 5 分钟脚本」

熟悉剪映、没用过 TripCut 的人:启动 → 首页「开始一个新旅程」→ 导入 → 引导气泡各出一次且不烦 → 空格/I/O/JKL 与剪映一致 →
镜头带像时间线(刻度、播放头、拖动)→ 「导入剪映继续剪」(或白话说明为何暂不可用)→ 全程无术语、无需进设置。

## 8. R14 入口

R12/R13 合并发布(0.7.0)之后,`docs/qa/2026-09-14-unattended-r12-r13.md` 记录的未决事项转入下一轮候选:

1. **剪映 11.4 白名单人工核验 → 放开默认**:`open_app` 目前白名单只有 `com.lemon.lvpro`,`SUPPORTED_JIANYING_VERSIONS` 尚未经业主在真实剪映 11.4 环境验证草稿可正常导入;业主人工验证通过后,再考虑把「导入剪映继续剪」/ 剪映草稿设为默认交付方式(而不是仅在白名单命中时才默认)。
2. **旧壳(LegacyShell / 四页 FirstRunGuide / Storyboard 的「上移/下移」)移除**:R12/R13 两轮的新组件(`PipelineRail`、`HomeScreen`、`ShotBand` 时间线化等)均只接进新壳主路径,旧壳组件(`LegacyShell.tsx`、`FirstRunGuide.tsx` 四页弹窗、`Storyboard.tsx` 的「上移/下移」按钮)仍在代码里但已不是任何主路径入口,是否整段移除、移除前要不要留一轮弃用观察期,留给 R14 拍板。
3. **X-06 首启空库启动短暂白屏根因**:R12 fix2 车道排查倾向「WebKit 在从未被激活的进程里某种冷条件下未起首个导航」,已用「正在准备工作台…」占位缓解,根因仍未锁定;若业主真实使用路径(Dock/访达启动)也观察到,需要进一步查 WebKit 侧(`WKWebView` 进程日志)。
4. **CLIP 加权**:R11/R12 的「有人声」判定与时刻分打分权重仍是零模型启发式(RMS + 峰均比、清晰度/运动/曝光/有声/无切换五项固定权重);CLIP/Whisper 等本地模型可用后,时刻分与自动挑选的打分应改为按模型输出加权,而不是纯启发式,需要单独设计一轮。
5. **交付候选池方案**:R13 车道 C 的拖边裁剪不迁移旧段星级(评级挂在 `segment_id` 上,裁剪走「新建→换引用→删旧」会换 id);是否需要一套「候选池」模型(段的身份与其评级/来源解耦,裁剪只改时间区间不换身份),留给 R14 与后端命令一起设计。
6. **深色主题打磨**:R13 新增的「剪映风格深色」主题目前只钉住 27 个必须重定义的 token 键做到「可用不报错」,尚未做整体视觉走查(对比度、图标在深色下的可读性、`preview:shots` 的深色截图覆盖);建议 R14 排一轮专门的深色主题视觉打磨与截图验收。

## 9. R14 · 剪映交接补全(业主 09-14 拍板:多 agent 快速完善)

现状:草稿只验过 11.3.0;业主机器是 11.4.13189(草稿加密),应用拒绝生成 → 「导入剪映继续剪」在真机上是死路。

- **A 试验开关**:导出抽屉「剪映草稿」在版本不在白名单时提供「我知道风险,仍然试着生成(试验)」:写出 11.3.0 格式草稿到剪映草稿根目录(**新名字**,永不覆盖),结果卡上给「打开剪映 → 看草稿列表里有没有它 → 能打开就回来点『可以用』」三步;「可以用」/「打不开」两个按钮把结果写进 settings(`jianying.human_check.<version>` = ok/fail)并上报到状态条;`ok` 后该版本视为已验证(前端与 Rust 共同判定:白名单 ∪ human_check ok),默认交接改回草稿。Rust:`generate_native_draft(force: bool)`,force 只放行「待人眼验证名单」里的版本,不放行未知版本。
- **B 素材包交接(永远可用)**:新模式「剪映素材包」:按镜头带顺序把精选段/整条导出为 `NN_<章名>_<素材名>.mp4`(帧精确 remux,同 quick_export),附 `顺序.txt`;完成 toast「已导出 n 个片段 · 打开剪映」+ 说明「在剪映里新建草稿 → 全选这些文件拖进时间线,顺序即镜头带顺序」;剪映不可用(未验证)时导出抽屉默认落到这条,「导入剪映继续剪」按钮文案改「导出剪映素材包」。Rust:`export_jianying_kit(dest_dir?) -> {dir, files}`,复用 quick_export 管线 + 命名。
- **C 草稿内容补齐**(A 验证 ok 后才有意义,但可先做、受同一闸门):章节 → 剪映 `time_marks`/文本标题片段(11.3.0 模板允许的字段内);配乐轨(`materials.audios` + 音频轨,含入点);集名作草稿名;测试用金样键集校验不新增未知键。
- 验收:真机 11.4 上 A 能写出草稿并给出三步提示(业主真手完成剪映侧检查);B 在真机导出 6 段、编号顺序与镜头带一致、打开剪映成功;C 在 11.3.0 金样键集测试内。
