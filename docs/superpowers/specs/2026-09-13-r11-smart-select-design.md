# R11 智能选段、一键导出、更聪明的播放器(0.5.0)

业主诉求(2026-09-13):1. 软件要能**帮我选精选片段**;2. **素材导出简单一点**;3. **播放器更智能一点**。
前提:零模型可用(不依赖 CLIP/Whisper/LLM),有了再增强;原片只读;不碰 `player/mod.rs`。

## 1. 帮选精选片段 —— 「时刻分」与建议段

现状:分析是**每条一个分**(`clip_analysis`/`clip_motion`),没有时间轴;精选段全靠手打入出点。

**1.1 时刻分时间轴(Rust,车道 B)**
- `analysis.rs` 已经跑 `signalstats / blurdetect / vmafmotion / astats`,只是聚合成整条。改为同时**按 0.5 s 窗口落盘**:新表(迁移 0043)`clip_moments(clip_id, win_index, t_start_ticks, t_end_ticks, sharp, motion, exposure_ok, loud, speech, score, reasons_json)`。`speech` 先来自 `astats` 的动态范围 + 有转写时的 `transcript_segments` 覆盖;`score` = 加权(清晰 0.3、运动适中 0.25、曝光正常 0.2、声音有内容 0.15、无场景切换 0.1),权重放 `settings` 可调。
- 老库:导入时已分析过的素材由「补齐时刻分」后台任务增量补(状态条可见),不阻塞使用。
- 命令:`suggest_segments(clip_id, target_secs?) -> Vec<SegmentSuggestion{in,out,score,reasons}>`——按目标时长(平台预设 4–8 s,可传)在时刻分上滑窗取峰,峰间距 ≥ 目标时长,过滤场景切换跨越,最多 3 条;`auto_select_episode(budget_secs?, scope: favorites|rated3|all) -> AutoSelectOutcome`——按章节覆盖轮转,从每条最高分建议里挑,直到凑够平台时长预算,写成 `segments`(标记 `source='auto'`,可一键撤销整批)。

**1.2 界面(车道 C,监视器;车道 A,媒体池)**
- seek bar 下加**热力条**(时刻分),建议段画成半透明区块;当前建议高亮。
- 选中素材默认**从最高分时刻开始播**(设置项,默认开);`Enter` 采纳当前建议为精选段,`N`/`⇧N` 下一条/上一条建议,`I`/`O` 仍可微调后再 `S` 保存。
- 媒体池卡片:有建议的素材右下角小闪电角标;顶栏「导入素材」旁不加按钮——「自动挑选精选段」放在镜头带工具条(与「按章节/按时间/仅缺口」同行),弹小面板选范围(收藏 / ≥3 星 / 全部)与预算,结果 toast 带「撤销这批」。

## 2. 素材导出简单一点(车道 E)

- 交付抽屉顶部加**模式**两枚 chip:「快速导出」(默认;只出 `精选原片` + `整条收藏`,不出粗剪/PDF/CSV)与「完整交付包」(现状)。快速导出记住上次文件夹(`ui.export.last_dir`),**不弹保存面板**,完成后 toast「已导出 n 个文件 · 在 Finder 中显示」。
- 检查器「精选段」区与媒体池多选右键:「导出所选…」直接走快速导出(只导这些)。
- 输出文件夹命名沿用 `<集名>_导出_<日期>`;同名追加 `-2`。

## 3. 播放器更智能一点(车道 C)

- 播到尾:按设置「播完自动下一条」(默认开,顺着当前筛选顺序;到末尾停下);`L` 长按/再按 = 2×/4×,`J` 反向,`K` 停(已有)。
- `,` / `.` 逐帧(按素材帧率算 1 帧);`⌥←/→` ±5 s。
- 入出点后按 `⇧L` 循环播放入出区间(打点时反复看);保存后循环自动关。
- 媒体池卡片 **悬停刮擦**:鼠标横向滑过缩略图按比例预览(用已有的帧条缓存 strip;无缓存时退化为静态封面);移开恢复封面。
- 音量与静音记忆;切素材不重置。
- 播放器状态行显示「建议 2/3 · 6.0 s · 清晰·运动适中」这种可读原因。

## 4. 风险控制

- 迁移 0043 只**加表**;时刻分失败不影响既有分析结果(任务独立、可重跑)。
- 自动挑选只**新增** `segments`(`source='auto'`),一键整批撤销;从不改用户手打的段。
- 快速导出仍是 remux/拷贝,不重编码;目标目录不存在或不可写时回落到保存面板。
- 播放器改动只在前端与既有 `player_*` 命令;任何触到视口提交的改动要真机复核。
- 不做:人脸/人物识别(无模型)、LLM 挑选;CLIP 可用时把「画面语义」作为第 6 个权重加进时刻分(后续)。

## 5. 验收

- 21 条真机走查素材:每条 ≥1 条建议,`auto_select_episode` 30 s 预算得到 ≥4 段、覆盖 ≥2 章;`Enter` 采纳 → 检查器精选段区出现;快速导出 → 文件夹里只有 remux 的段与收藏;播完自动下一条、逐帧、循环、悬停刮擦在真机各验一次;门禁 + 稳定性烟测 0 崩溃。
