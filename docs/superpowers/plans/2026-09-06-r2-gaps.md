# R2 缺口前 15 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把审计里"后端有、前端没接"和"用户会直接撞上"的 15 项缺口补齐：外置盘重连、相似镜头对比、旁白稿、隐私与诊断分区、可访问性、评级计数、列表增量、拖放导入、崩溃恢复回归、删除撤销、只读探测不迁移、分包。

**Architecture:** 前端接线类任务各自独立组件 + 只由接线人改 `App.tsx` 路由；后端小改动各带单测；每项都有可无人值守自动验证（vitest / cargo test / 脚本），需要 GUI 的以冒烟脚本新增一条内容断言为验收。

**Tech Stack:** React 19 + TS（vitest + testing-library）、Rust（rusqlite）、Tauri 2 `onDragDropEvent`、Vite/rolldown `manualChunks`、zsh 脚本。

## Global Constraints

- 规格 §3；总计划 Global Constraints 全部适用。cargo：`export PATH=/opt/homebrew/opt/rustup/bin:$PATH`。合并门禁 `node scripts/qa/fast-gates.mjs` PASS；合并后 push。
- 车道在 worktree（`git worktree add ../tripcut-wt-<项> -b feat/<项>`，`CARGO_TARGET_DIR=$HOME/Projects/tripcut-studio/src-tauri/target`）；接线人合并。`App.tsx` 与侧栏只由接线人改。
- 原片只读；任何"删除"都是软删除或可撤销；历史集只读边界（`ensure_clip_writable`）不得绕过。
- 文案中文；快捷键改动要过 IME 组合态守卫（`event.code` + `isComposing`）。
- 每个前端任务：`npm run typecheck && npm run lint && npx vitest run <相关测试>`；每个后端任务：`cargo test … <模块>` + clippy。
