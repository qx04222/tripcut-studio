# 旅剪工作台 · 快速上手

旅剪工作台位于拍摄和剪映之间：先把大量旅行素材整理成清晰、可恢复的故事工作集，再进入正式剪辑。

> 原片只读。TripCut 不会覆盖、移动或删除相机原文件。

## 1. 安装预览版

当前 `v0.1` 仅支持 Apple Silicon，并采用 ad-hoc 签名。

1. 从本项目 GitHub Release 下载带 `preview_aarch64` 的 DMG；
2. 对照 `SHA256SUMS.txt` 核对文件；
3. 把“旅剪工作台”拖入 Applications；
4. 若 macOS 阻止首次启动，在“系统设置 → 隐私与安全性”中核对后选择“仍要打开”。

不要关闭 Gatekeeper，也不要批量移除文件隔离属性。完整边界见 [未签名预览说明](UNSIGNED_PREVIEW.md)。

## 2. 一条完整工作流

```text
素材文件夹 → 引用式导入 → 筛片与评级 → Episode / 故事板 → 精选段 → 稳定交付包 → 剪映
```

### 导入

选择相机卡、移动硬盘或本地素材文件夹。TripCut 建立只读索引，并在后台读取画面、声音、时间和质量特征。

经常更新的目录可以设为 watched folder。移动硬盘或 NAS 暂时离线时，应用会显示不可用状态，不会把离线误报成“没有新素材”。

### 筛片

- `F`：收藏；
- `X`：拒绝；
- `1`–`5`：星级；
- `0`：清除评级；
- 双击卡片或按空格：打开播放器；
- `I` / `O`：设置入点和出点；
- `S`：保存精选段。

质量角标用于辅助判断，不会自动删除素材。人物、信息和意外镜头应由创作者最终决定。

### Episode 与故事板

一条 Vlog 对应一个 Episode。完成后封存本集，历史集进入只读状态，新素材进入下一集；跨集标记可以提醒镜头是否已经使用。

故事板按章节与 Beat 组织素材。AI 建议与用户确认结果分开保存，人工调整始终优先。

### 交付剪映

“稳定交付包”会生成：

```text
01_精选片段/
02_参考粗剪.mp4
03_镜头表.csv
03_字幕/
交付说明.txt
```

先在 Finder 检查交付包，再把素材和参考粗剪导入剪映。原生剪映草稿仍是实验功能，不应替代稳定交付包。

## 3. 本地 AI 与隐私

- 核心导入、筛片、故事板和交付不依赖云端 AI；
- FFmpeg、FFprobe、libmpv 与 whisper-cli 已随应用提供；
- Whisper 模型由用户自行选择，不随 DMG 分发；
- L3 大模型增强默认关闭；
- 应用不会静默上传视频或音频。

如启用外部 AI provider，请先阅读界面中的数据摘要和预算提示。

## 4. 数据与备份

项目数据库、缩略图、代理文件和日志默认保存在当前 macOS 用户的 Application Support 目录。缓存可以重建，数据库记录不能替代原片备份。

建议始终保留：

- 至少一份独立原片备份；
- 重要 Episode 的稳定交付包；
- 升级前的项目数据库快照。

## 5. v0.1 已知边界

- 仅支持 Apple Silicon；
- 未签名、未公证、没有自动更新；
- Chinese-CLIP 组件尚未随公开预览包交付；
