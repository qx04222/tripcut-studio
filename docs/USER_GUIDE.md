# 旅剪工作台 · 快速上手

旅剪工作台位于拍摄和剪映之间：先把大量旅行素材整理成清晰、可恢复的故事工作集，再进入正式剪辑。

> 原片只读。TripCut 不会覆盖、移动或删除相机原文件。

## 1. 安装预览版

当前 `v0.1` 仅支持 Apple Silicon，并采用 ad-hoc 签名。

1. 从本项目 GitHub Release 下载带 `preview_aarch64` 的 DMG；
2. 对照 `SHA256SUMS.txt` 核对文件；
3. 把“旅剪工作台”拖入 Applications；
4. 若 macOS 阻止首次启动，在“系统设置 → 隐私与安全性”中核对后选择“仍要打开”。

不要关闭 Gatekeeper，也不要批量移除文件隔离属性。完整边界见 [未签名预览说明](UNSIGNED_PREVIEW.md)。

## 2. 一条完整工作流

```text
素材文件夹 → 引用式导入 → 筛片与评级 → Episode / 故事板 → 精选段 → 稳定交付包 → 剪映
```

### 导入

选择相机卡、移动硬盘或本地素材文件夹。TripCut 建立只读索引，并在后台读取画面、声音、时间和质量特征。也可以直接把文件夹或视频文件拖到导入页，松开即导入。

经常更新的目录可以设为 watched folder。移动硬盘或 NAS 暂时离线时，应用会显示不可用状态，不会把离线误报成“没有新素材”。

**外置盘重连**：如果素材所在的移动硬盘换了盘符或路径，导入页顶部会出现「缺失素材」面板，按卷分组列出缺失文件；点「选择新位置」后按内容哈希重新绑定路径，文件名相同但内容不同的文件会被拒绝并单独列出，不会误绑。

**内存档位**：内存 24 GB 以下的机器自动走省内存档，降低解码并发；系统内存紧张时会暂停解码与模型任务，并在导入页给出提示。也可以在设置的性能分区手动指定档位（自动 / 标准 / 省内存）。

### 筛片

- `F`：收藏；
- `X`：拒绝；
- `1`–`5`：星级；
- `0`：清除评级；
- 双击卡片或按空格：打开播放器；
- `I` / `O`：设置入点和出点；
- `S`：保存精选段。

质量角标用于辅助判断，不会自动删除素材。人物、信息和意外镜头应由创作者最终决定。

右侧的「相似镜头」面板可以查看同组的相似镜头，点「设为主镜头」调整哪条作为该组的代表；历史集为只读档案，面板里不能切换。

保存精选段后误删了不用担心：删除后 10 秒内界面上会出现「撤销」按钮，点一下即可恢复。

**画面文字识别**：缩略图生成后自动在本机跑一遍离线 OCR（中英文），结果显示在右栏「画面文字」角标；⌘K 全局搜索覆盖到画面文字，命中会标「画面文字」来源。识别工具未安装时该任务显示「组件未安装」，不影响其他分析任务。

**竖屏过滤**：筛片过滤工具条新增「竖屏」勾选，按 rotation 与画面比例判定只看竖屏素材。

**拼音搜索**：全局搜索（侧栏或 ⌘K）输入两个以上英文字母（如 `lvpai`、`lp`）也能命中中文文件名/标签/章节标题里的「旅拍」，不用切输入法；命中来源徽章会标「拼音」。搜到的是历史集素材时，点击打开的是该集的只读历史视图，不会切换当前集的过滤条件。

### Episode 与故事板

一条 Vlog 对应一个 Episode。完成后封存本集：确认对话框里可以顺手为下一集选目标平台与画布方向（默认沿用当前集），确认后历史集进入只读状态，新素材进入按你所选设置开启的下一集；跨集标记可以提醒镜头是否已经使用。

「重命名本集」表单新增**目标平台**（抖音 / 小红书 / B站 / 朋友圈 / 家庭纪录 / 通用）与**画布方向**（横屏 / 竖屏 / 同时）；标题旁的徽章会显示当前设置，例如「抖音 · 竖屏」。交付页另有「本次交付平台」下拉，可以临时用别的平台规格导出这一次，不影响本集的设置。

故事板按章节与 Beat 组织素材。AI 建议与用户确认结果分开保存，人工调整始终优先。

**故事模板**：编排前可以在故事板顶部选一张模板卡——电影感 / 快节奏 / 安静氛围 / 旅行日记，或「不使用模板」。没有连上 AI 助手也能编排：软件会按模板规则生成一版确定性的编排，理由文本会标明「未启用 AI，按模板规则生成」；接上 AI 助手后重新编排会覆盖建议版，不影响已确认内容。

**音乐与节奏**：故事板右侧新增「音乐与节奏」页签。导入一条音乐文件只记录其绝对路径、不复制；文件被移动或删除会被提示找不到。分析给出 BPM、节拍点与段落（前奏 / 主歌 / 推进 / 高潮 / 尾声 / 其他），分析中每 3 秒自动刷新；点波形上的切点建议只复制时间，不改写任何入出点。检测不到明显节拍的曲目会标为分析失败。历史集只读，不能导入或删除音乐。

**旅程时间线**：故事板右侧另一个页签，把本集素材按跨设备校正过的标准拍摄时间重排成按天分组的时间线（地点卡 + 缩略图），没有时间信息的归入「未标时间」；只读，用来核对故事顺序是否符合真实旅行顺序。

### 技术检查

筛片右栏新增「技术检查」面板：分辨率、实际帧率（含 VFR 标注）、编码、方向、色彩（转移函数，D-Log / HDR 会加徽章）、ISO / 快门 / 光圈（设备未记录时显示「设备未提供」），以及全部音轨——可以逐条「监听」试听，也可以「设为转录轨」指定转写用哪一路；每条音轨标有角色猜测（机内麦克风 / 无线麦克风 / 备份轨 / 未知）。面板底部是「显示 LUT」下拉，选一个 `.cube` 文件后播放器按它预览色彩，**LUT 只影响预览，不影响导出**；LUT 文件放在应用支持目录下的 `luts/` 文件夹。

**多声道音轨**：导入时会记录素材的全部音轨并做角色猜测；转写默认使用选定的那一路（未选择时用第 0 路）。生成剪映草稿时，多轨素材的素材名后面会追加音轨映射，例如 `clip.mov [音轨映射 0=机内麦(转录)/1=无线麦]`，方便在剪映里核对声音来源。

> R3 之前导入的旧素材没有音轨记录，需要在技术检查面板里点一次「探测音轨」才会补上音轨列表与拍摄参数；新导入的素材会自动记录。

### 交付剪映

“稳定交付包”会生成：

```text
01_精选原片/            按推荐顺序编号的素材
02_环境声与旁白/旁白稿.txt  按叙事分章生成的旁白草稿——已确认的修订按“已确认”写入；未确认的 AI 建议修订也会写入草稿，但文件头会标注“（AI 建议稿，未经人工确认）”，需人工核实后再配音
03_字幕/                与素材同序号的 SRT 字幕
04_参考粗剪/参考粗剪.mp4 串好的参考视频
05_镜头表/剪辑清单.csv   每条素材的包内路径、参数、星级、对白摘要、平台、画布、转录音轨
05_镜头表/联系表.pdf    A4 网格联系表(默认勾选生成)
06_LUT与色彩说明/       色彩说明(后续版本)
07_地点卡/              目的地信息卡
交付说明.txt
```

交付页默认勾选「联系表.pdf」：A4 网格联系表，每张卡片是封面缩略图 + 序号/文件名、入出点、章节标题三行文字，横屏排 4 列、竖屏排 3 列，随本次画布方向自动切换。内嵌中文字体，个别生僻字缺字体时显示为「□」，交付说明.txt 会写明具体缺字数量。可在交付页取消勾选。

交付说明.txt 会写明本次的目标平台、画布尺寸和建议时长（如「目标平台：抖音（竖屏 1080×1920，建议时长 ≤ 60 s）」）；若有素材探测到 2 路以上音轨，还会追加一句音轨映射说明。生成剪映草稿时，画布尺寸按平台预设生成，不再固定按第一条素材的分辨率。

交付页新增「参考粗剪时长」下拉：完整 / 30 秒 / 60 秒 / 3 分钟。选定档位后参考粗剪按 Beat 顺序在预算内截取；若目标平台设了时长预算，会自动预选一个不超预算的最大档位，没有档位能塞进预算时回退到「完整」。

先在 Finder 检查交付包，再把素材和参考粗剪导入剪映。原生剪映草稿仍是实验功能，不应替代稳定交付包。

## 3. 本地 AI 与隐私

- 核心导入、筛片、故事板和交付不依赖云端 AI；
- FFmpeg、FFprobe、libmpv 与 whisper-cli 已随应用提供；
- Whisper 模型由用户自行选择，不随 DMG 分发；
- L3 大模型增强默认关闭；
- 应用不会静默上传视频或音频。

如启用外部 AI provider，请先阅读界面中的数据摘要和预算提示。

设置页新增「隐私与诊断」分区，列出确切留在本机的内容、诊断日志位置，以及崩溃报告由 macOS 系统设置控制的说明。

设置页「工具链」分区新增「回滚到上一版」：FFmpeg、FFprobe、Whisper 与转写模型如果存在上一版本，会出现这个按钮，装了新版本发现有问题可以一键退回；没有上一版本时按钮不出现。

设置页「帮助与关于」新增「检查更新」按钮：软件不会自动检查，只在点击时联网查一次；发现新版本可「下载并安装」，签名校验失败会拒绝安装并给出中文提示，不影响现有程序；安装完成后「立即重启」生效。交付完成、批量 AI 分析完成会各发一条系统通知；电脑睡眠期间的任务会在唤醒后自动续跑，不用手动重试。

## 4. 数据与备份

项目数据库、缩略图、代理文件和日志默认保存在当前 macOS 用户的 Application Support 目录。缓存可以重建，数据库记录不能替代原片备份。画面文字识别结果只存在数据库里，识别在本机离线完成；导入的音乐文件不会被复制，数据库只记录其绝对路径。

建议始终保留：

- 至少一份独立原片备份；
- 重要 Episode 的稳定交付包；
- 升级前的项目数据库快照。

## 5. v0.1 已知边界

- 仅支持 Apple Silicon；
- 未签名、未公证；应用内已有「检查更新」机制（手动触发、minisign 验签），但公开仓库尚未发布签名证书与 `latest.json`，当前预览包点「检查更新」查不到新版本；
- Chinese-CLIP 组件尚未随公开预览包交付；
- Whisper 模型需要用户自行准备；
- 剪映草稿兼容仍属实验功能；
- Alpha 数据结构未来可能调整。
