Application dependencies
------------------------

The in-app Open-Source Licenses screen lists the direct Cargo and npm
dependencies, locked versions, SPDX license expressions, ecosystem, and
runtime/build/development scope. Every packaged native Mach-O file is mapped to
a component, SPDX expression, artifact hash and bundled license evidence in
legal/native-sbom.json. Homebrew bottle SPDX records and selected license and
copyright materials for dynamic dependencies are retained under legal/native/.
