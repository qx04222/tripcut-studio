# 旅剪工作台 v0.7.1 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名):首次打开需在「系统设置 → 隐私与安全性」里允许,
> 或右键 →「打开」。0.7.0 及更早版本可通过应用内更新升级到本版。

0.7.0 发布后紧接着的小修版,把压力测试里剩下的几项补齐:

- **全屏沉浸恢复满屏**:此前按 ⌘⏎ 进入沉浸播放时画面只占中间一小块,现在铺满整个窗口(横竖屏都验过)。
- **导出失败的原因说人话**:不再出现 `export failed` / `os error 13` 这类内部字样,系统原因翻成中文;有失败项时页脚不再写「导完了」。
- **参考粗剪体积合理**:输出码率按原片的 1.5 倍封顶(过去可能达到原片的 7 倍)。
- **章节时间按当地时间显示**(尊重设备时钟校正),不再是 UTC。
- **预览小文件不再比原片还大**,「项目与缓存」里说明了预览文件的占用。

其余内容与 0.7.0 相同(见 `v0.7.0.md`)。
