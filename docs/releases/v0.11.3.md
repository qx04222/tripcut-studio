# 旅剪工作台 v0.11.3 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。0.8.3+ 用户会自动收到,点「重启完成更新」即可。

## 镜头带精修:像剪映时间线那样顺手

- **多选与批量**:点一个再 ⇧ 点另一个是连选,⌘ 点是加减选,空白处拖一个框就是框选,⌘A 全选;标题栏右侧显示「已选 N」,旁边有「移到章」「批量评级」「移出所选」。Delete / Backspace 直接把选中的段移出镜头带(原片和精选记录都还在)。
- **拖动更跟手**:拖一段(或选中的一组)时旁边的段会让位,靠近别的段和章的边界会吸上去(按住 ⌥ 关掉吸附);可以直接拖到另一章,拖到栏左右边缘会自动横向滚;拖章头就是整章挪位。
- **拖边修剪时监视器跟着走**:拖某段的入点 / 出点把手,监视器实时停在那一帧,把手上有时码气泡;拖到素材边界会钳住并抖一下提示。`[` / `]` 把所选段的入 / 出点设到当前播放头。
- **缩放与导航**:⌘+ / ⌘− / ⌘0 缩放镜头带,⌥ + 滚轮以鼠标位置为中心缩放,普通滚轮横向滚动,按住空格拖动可以平移;最小档只留色条和时长,一眼看整条节奏。缩放和折叠按集记住。
- **章节**:双击章名改名(回车保存、Esc 取消),章头显示段数和总时长,点箭头折叠 / 展开;空章提示「拖段进来或删除」。
- **缺口**:相邻的缺口合成一张卡显示「缺 2 类」;每个缺口的「···」可以「从池里填」(打开媒体池并按类型预填筛选)或「忽略这个缺口」(可从标题栏「···」恢复)。缺口没有起止时间,也不占镜头带时长。
- **看得更清**:标题栏「···」可以打开评级星 / 收藏 / AI 理由角标;鼠标在镜块上停一下显示原素材名和入出点。
- **空态**:镜头带空的时候写着「按 F 收藏几条,再点一键排入」;已有镜头时按钮变成「补充排入」,只加入还没排进来的精选段和收藏 / 三星以上的整条素材。
- **全部可撤销**:移动、移出、修剪、改章名、忽略缺口……每一步都是一条 ⌘Z,提示里也有「撤销」。
- **300 段也不掉帧**:300 个镜块的镜头带拖动掉帧从 46.5% 降到 2–4%(与 39 段一个水平)。

## 连播和镜头带一起用

- 连播中 ⇧ / ⌘ 多选、框选或拖动段,连播会停下(素材继续播),和拖进度条一样。
- 连播中拖当前段的入 / 出点把手:连播先暂停、监视器跟着把手走,松手后按新的入 / 出点接着播;把当前段移出镜头带就停止连播。
- 修了两个连播的问题:修剪或排入之后连播会莫名其妙停掉;连播播着的时候镜头带上的修剪把手按不动。

## 说明

- 视图设置(缩放 / 折叠 / 角标)不进 ⌘Z、不弹提示;⌘Z 只撤数据编辑。没有 ⇧⌘Z 重做。
- 跨章拖动只改这一段在镜头带上的归属,源素材和它的其它段不动。
- 只有 1 个镜头的章,章头会被压窄,折叠箭头和序号看不到(基线即有,下轮处理)。
- 完整无人值守验收记录见 `docs/qa/2026-09-22-unattended-r22c.md`(合入 / 接线 / 真机)与 `docs/qa/2026-09-21-unattended-r22-band.md`(镜头带车道)。
