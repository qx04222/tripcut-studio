# 旅剪工作台 v0.2.0 · 未签名预览版

这一版把小内存设备的整机流程压下来，给筛片和故事板加了一整轮新工具，交付包也更接近能直接拖进剪映用。

## 性能（小内存设备）

- 缩略图、分析、胶片条、代理生成全面优先走硬件解码（VideoToolbox），软解只作回退；封面缩略图先缩放再选帧，实测单素材峰值内存从 1.74 GB 降到 0.78 GB。
- 500 条 4K 素材的全流程实测（M5/32 GB 自动化装置）：整机峰值内存从 7.42 GB 降到 3.80 GB（约减半），全流程总耗时从 54.6 分钟降到约 32 分钟，首屏 24 张封面从 55.6 秒降到约 24 秒（封面与胶片条拆成两步，封面先行）；省内存档约 28 秒。
- 新增内存档位（自动 / 标准 / 省内存），24 GB 以下内存的机器自动走省内存档；导入中若系统可用内存跌到过低，会暂停解码与模型任务并在导入页提示，恢复后自动继续，暂停不影响正在跑的导出。

## 筛片

- 右栏新增「相似镜头」面板，可比对同组素材并把某条设为该组代表。
- 技术检查面板：色彩空间、横竖屏、多声道音轨、拍摄参数（ISO / 快门 / 光圈）一处查看；显示 LUT 仅影响播放器预览，不改变原始文件。
- 素材筛选新增「竖屏」过滤，按旋转与画面比例判定，含拍摄时物理转了 90°/270° 但文件本身仍按横向存储的素材。
- 缩略图生成后自动在本机跑一遍画面文字识别（离线、不联网、中英文都认），识别结果显示在右栏「画面文字」角标里。
- 导入页支持把文件夹或视频直接拖进来导入。
- 保存精选段后按「删除」，10 秒内可点「撤销」恢复，超时后需要重新框选。

## 故事板

- 「一键 AI 编排」前可选四种故事模板——电影感 / 快节奏 / 安静氛围 / 旅行日记，编排逻辑各不相同；没有配置大模型时也有确定性兜底，仍按模板产出不同结果。
- 新增「音乐与节奏」页签：导入一条参考音乐，看节拍和段落分布方便卡点，仅供参考、不会替你重排镜头；分析不出节拍的曲目会标为「分析失败」。
- 新增「旅程时间线」页签，按跨设备校正过的拍摄时间把素材重排成时间线、按天分组，用于核对故事顺序，只读查看。

## 搜索

- 支持拼音 / 首字母搜索中文文件名、标签、章节标题（两个字母以上，如 `lvpai` 或 `lp`）。
- 每条搜索结果标来源徽章（文件 / 转写 / AI / 标签 / 画面文字 / 拼音）。
- 命中已封存历史集的结果打开只读历史视图，不会打断当前集的筛选状态。

## 交付

- 交付包目录改为编号 01–07（精选原片、旁白稿、字幕、参考粗剪、镜头表、地点卡等），结构更清楚。
- 新增可选的「联系表.pdf」：A4 网格，缩略图 + 序号/文件名 + 入出点 + 章节，跟随画布方向排版，内嵌中文字体。
- 新建集与交付页可选目标平台预设（抖音 / 小红书 / B站 / 朋友圈 / 家庭纪录 / 通用）与横竖画布方向，交付说明、字幕、剪辑清单、剪映草稿画布尺寸都跟着走；交付页可临时用别的平台规格导出一次，不影响集本身的设置。
- 「参考粗剪时长」下拉：完整 / 30 秒 / 60 秒 / 3 分钟，按 Beat 顺序在预算内截取；设了平台时长建议时会自动预选一个不超预算的档位。
- 旁白稿按叙事分章生成；已确认的修订标注「已确认」，尚未人工确认的叙事修订也会按 AI 建议写入草稿，但文件头标注「（AI 建议稿，未经人工确认）」，提醒配音前先核实。
- 「生成剪映草稿」的画布尺寸按平台预设生成，不再固定按第一条素材的分辨率；导出遵循素材的旋转设置，不会二次旋转。

## 集（Episode）

- 新建集与「封存本集」都可以选目标平台与画布方向；封存时可顺手为下一集选好设置（默认沿用当前集）。

## 系统

- 电脑睡眠期间有任务在跑，唤醒后自动接着跑完，不需要手动重试。
- 交付包生成完成、批量 AI 分析完成时会收到 macOS 系统通知，切到别的应用也能看到。
- 「设置 → 工具链」里，FFmpeg / Whisper 组件如果存在上一版本，可以一键「回滚到上一版」。
- 崩溃恢复：异常退出后重新打开会先只读探测再决定是否迁移，避免带着半损坏的数据库硬跑。
- 「设置」新增「隐私与诊断」独立分区，列出确切留在本机的内容与诊断日志目录入口。
- 「设置 → 帮助与关于」新增「检查更新」——首次接入，软件不会自动检查，只在点击时联网查一次；这仍是未签名预览版，本机没有已发布的签名更新端点时点击查不到新版本，Gatekeeper 对下载下来的安装包仍可能拦截，请按提示核对来源后放行。

## 无障碍

- 搜索结果补上 listbox 语义、评级计数按当前集口径、多模态弹层收紧焦点约束，改善键盘与读屏体验。

## 升级与边界

数据库 schema 从 29 升到 40，并在迁移前保存快照。**升级后的库不要用旧版应用打开**；需要回退时使用升级前的数据库快照。

这是 Apple Silicon / arm64 的 ad-hoc 签名预览版，没有 Apple Developer ID 或 Apple 公证。请核对 SHA-256；详见 [未签名预览版说明](https://github.com/qx04222/tripcut-studio/blob/v0.2.0/docs/UNSIGNED_PREVIEW.md)。Whisper 转写模型与 Chinese-CLIP 语义检索模型仍由用户自行配置，不随安装包分发。本版性能数字来自 500 条素材的自动化装置实测（M5 / 32 GB），16 GB 真机验收与内存压力暂停在真实设备上的表现不包含在本次结果中。
