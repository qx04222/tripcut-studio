# 旅剪工作台 v0.3.0 · 未签名预览版

界面改为单屏导演台；旧界面可在设置 → 外观 →「切回旧界面」临时恢复，下一版移除。

> 未签名、未公证的预览版（ad-hoc 签名）：首次打开需在「系统设置 → 隐私与安全性」里允许，
> 或右键 →「打开」。旧版可通过应用内更新升级到本版。

## 界面成品化（这一轮打磨）

上一轮预览版发出去之后，业主反馈「需要特大优化才能使用」：主屏看得出栏位但分不清
层次，预览画面是一块空的米色方块，素材卡片的文件名中间被省略号切掉认不出是哪条素材，
三个弹出面板（导入、生成交付包、设置）其实是把旧的整页界面硬塞进一个 700 像素宽的
抽屉里，里面还留着一些没翻译的英文小标题和装饰性的序号水印。这一轮针对性地重做了
这几处，功能和数据一个字都没有变：

- **主屏更有层次**：顶栏、每一栏的标题条、底部状态条现在有清楚的深浅分层和投影，
  不再糊成一片背景色；预览画面区改成深色底的取景框，更接近视频剪辑软件的观感；
  素材卡片的文件名改成两行显示、按下划线断行，不再从中间被省略号切掉（文件名特别长
  时最后一小截仍会被裁掉，这一点还在等业主看图拍板要不要再多留一行）。
- **拖动分隔条现在看得见、也好拖**：三栏之间的分隔条从几乎看不见的一条细线，变成
  6 像素宽、带抓手的可见分隔条，鼠标移上去或拖动时会变成强调色。
- **素材卡片、按钮都有了统一的悬停和选中反馈**：鼠标移到卡片上会轻微浮起，选中的
  卡片有清楚的双重高亮环；所有按钮、开关、下拉框都用同一套外观语言，配了一套统一
  风格的线条图标。
- **导入、生成交付包、设置这三个弹出面板整个重新设计**：不再是旧整页塞进小容器，
  而是按弹出面板的尺寸重新排版——导入面板分成「来源 / 任务 / 缺失素材」三个标签页；
  生成交付包面板变成一张干净的表单（选平台、选时长、要不要联系表、要不要剪映草稿）加
  一行汇总和一个主按钮；设置面板改成左侧分类、右侧对应内容的常见设置页布局。英文小
  标题和序号水印全部去掉。所有原来能做的事、原来的文案，一个字都没有少——只是重新
  排了版。
- **空状态不再是占位文字**：素材池还没有素材、没有筛选结果、预览区还没选素材、
  镜头带还没有章节、检查器还没选中任何东西，这几种情况现在都有对应的图标、说明文字
  和（在合适的地方）一个引导按钮。

**还没有解决 / 需要业主确认的**：预览画面在窗口里的精确对齐、拖动镜头顺序的手感，
这一轮的自动化检查依然拿不到真机像素证据（驱动进程还没有 macOS「屏幕录制」权限）；
镜头带下方展开音乐、旅程等附属内容时，默认给的高度偏矮，需要业主看过再定是否调高。

## 一屏三栏

原来的「左侧四步导航 + 四个页面」没有了。素材、画面、顺序、细节四件事同时在眼前：

- **媒体池**（左栏）：搜索、筛选 chips、2–4 列缩略图网格（500 条素材走行级虚拟化 + 2 行 overscan）。点一张卡片，另外两栏跟着换。
- **预览监视器**（中栏上半）：复用同一个 mpv 实例，不再为每条素材销毁重建；播放 / ±1 秒 / 速度 / 音量 / 时间码 / `I`·`O` 打点与「保存片段」，右端「全屏沉浸 `⌘⏎`」。
- **镜头带**（中栏下半）：按章节分组的镜头顺序，拖动改序（跨章节拖即改章节归属），空槽位是虚线卡片，点「生成候选」直接开云端补镜。
- **检查器**（右栏）：评级、标签、章节归属、Take 切换、AI 描述常驻；技术检查、八维、音轨与 LUT、相似镜头是折叠段，折叠状态逐段记忆。
- **后台状态条**（底部）：分析 / 转写 / 云端生成 / 缺失素材的计数，点它直接落到导入抽屉的「任务」分页。

镜头带下面那排分段控件 〈故事 · 音乐 · 旅程 · 地点卡 · 模板〉决定中下区展开什么：「音乐」在镜头带**上方**插一条 36px 刻度轨（节拍点、段落分界、建议切点，只做定位，不改任何数据），「旅程」展开只读的旅程时间线，「地点卡」展开当前章节的目的地卡，「模板」展开四选一的故事模板卡。

## 抽屉、sheet 与键盘

- 导入素材、生成交付包是从两侧滑出的抽屉；设置是从下方升起的 sheet（`⌘,`），都不离开工作区。
- 三者都有可见的「关闭」按钮，点抽屉外的遮罩也能关，`Esc` 一次只退一层（抽屉 → 设置 sheet → 沉浸 → 清空搜索词），关掉后焦点回到触发它的按钮。
- `⌘K` 命令面板 · `F6` / `⇧F6` 轮转栏焦点 · `⌘1` / `⌘2` 折叠媒体池 / 检查器 · `⌘⏎` 沉浸预览 · `?` 打开帮助。
- 窗口窄于 1280 自动折起检查器，窄于 1040 连媒体池一起折（折成 44px 竖条，随时点开），中栏永不折；三条分隔条可拖，宽度与比例都会记住。

## 旧界面与旧链接

- 旧的 `#/import`、`#/deliver`、`#/settings`、`#/review` 链接仍然有效，会自动转接到对应的抽屉 / sheet / 工作区。
- **旧的四页界面在这一版里完整保留**，可从「设置 → 外观 → 界面 →「切回旧界面」」热切换回去，不用重启。**下一个版本会移除它**——这一版是提意见的窗口期。
- 两套界面同时打包，这一个版本的包体因此偏大。

## 已知限制 / 待业主验证

- **1280×800 是最小可用尺寸，不是舒适尺寸**：三栏在该宽度下都接近各自的最小值，缩略图偏小。所有尺寸都是设置键，可调不改码；业主实机试用后如果不接受，下一版考虑给媒体池加「列表 / 网格」两档密度。
- 预览监视器在非全屏矩形下的 mpv 画面对齐、以及指针拖排的手感，都需要业主在真机上确认——自动化探针这一轮拿不到像素证据（驱动进程缺少 macOS「屏幕录制」权限，见 `docs/qa/2026-09-11-unattended-r8.md`）。
- 音乐带的切点只是建议，不写回任何数据；「按节拍排」的自动化留给后续版本。
- 精剪仍在剪映：本工具给的是顺序与选择，时间线上任何帧级意图都传不过去（交付包语义不变）。

## 真机复核（发布前最后一轮）

业主装上预览版后反馈「监视器和上面的 EP01 部分有重叠」。在真机上复核发现这不是排版问题：
预览画面是一块原生视图，永远画在网页界面之上，所以任何压到监视器上的弹层（切换集、
导入、生成交付包、设置、命令面板）都会被视频盖住；镜头带长高时视频也不会跟着缩。本轮修掉：

- 弹层打开时自动隐藏预览画面，关闭即恢复；预览画面严格留在监视器区域内，切换附属视图或
  拖动分隔条后会重新贴合。
- 修正原生视图的定位基准（此前漏算了 32 像素标题栏，画面会向上顶到栏标题条）。
- 修复一个只在真机出现的崩溃：播放中改变窗口大小时渲染线程与系统重建画布竞争导致闪退。
- 空章节各占一块并显示虚线占位；检查器标题不再被长文件名挤掉；没有封面的素材显示统一
  占位图标而不是破图；窄窗（1280）下卡片文件名三行完整显示。

已知未做：启动恢复页仍是旧风格；镜头带附属区默认高度偏矮（可拖动分隔条调整）。
