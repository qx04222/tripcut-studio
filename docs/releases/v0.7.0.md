# 旅剪工作台 v0.7.0 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名):首次打开需在「系统设置 → 隐私与安全性」里允许,
> 或右键 →「打开」。旧版可通过应用内更新升级到本版。

这一版把 0.6 和 0.7 两轮改动合在一起发:0.6 把散落的功能收进「一条流水线」,让新手一眼看懂自己在第几步、下一步该点哪里;
0.7 在此基础上向剪映的使用习惯靠拢——键位、设置分区、引导方式都改成剪映用户熟悉的样子,让从剪映过来的人几乎不用学。

## 0.6:一条流水线

- **四步导航条**:顶栏中央新增「① 导入 → ② 挑选 → ③ 排列 → ④ 导出」四步进度,当前在哪一步一眼看出,完成的步会打勾,点任意一步能直接跳过去。
- **「下一步:…」按钮**:顶栏主按钮不再是固定文案,而是随着你走到哪一步换成「下一步:导入素材」「下一步:自动挑选」「下一步:排到镜头带」「下一步:导出」,永远告诉你现在该点哪里。
- **挑好的片段自动进镜头带**:以前收藏或自动挑选出来的片段不会自动排进镜头带,第三步等于白等;现在挑选完成就自动排好顺序,一键排入也可以随时补排,排错了能整批撤销。
- **往前 / 往后**:镜头带里的片段除了拖拽排序,现在还有明确的「往前」「往后」按钮,不习惯拖拽也能调顺序。
- **Toast 提示**:自动挑选、撤销、排入、导出完成或失败,现在都用屏幕顶部一条简短的提示条告知结果,而不是藏在角落的小字。
- **分析还要多久**:导入素材后,状态条会尽量估算「大约还要 X 秒」分析完成,而不是只显示一个不知道要等多久的进度数字。
- **预览不自动播放**:点一张素材卡片只是预览、停在最出彩的那一刻,不会自动开始播放——按空格或点播放按钮才真正开始播,避免选片时画面到处乱跑。
- **连播开关**:「播完自动接下一条」现在是监视器上一个明确的开关,默认关闭,打开了才会自动接力播放下一条素材。
- **真变速**:2 倍速、4 倍速快进和反向逐帧现在是真正的原生变速播放,画面连续流畅,不再是"暂停后快速跳位置"的模拟效果。
- **术语说人话**:界面里进一步清理了一批内部代码词和技术黑话,比如"八维评分"改成"画面评分"、"音轨与 LUT"改成"声音与调色"、"索引"改成"登记"、完整交付包里的技术参数也换成了看得懂的说法。

## 0.7:向剪映对齐

- **剪映键位预设**:设置里新增「快捷键」分区,默认键位改成和剪映一致(空格播放、I/O 打入出点、方向键逐帧、J/K/L 走带、⌘Z 撤销、⌘E 导出等),从剪映过来的人不用重新记键位;也可以一键切换成 Premiere Pro、Final Cut Pro 的键位,或者自己逐个改。
- **剪映式设置**:设置页重新按剪映的分类方式整理成六块——「项目与缓存 / 快捷键 / 播放与导出 / 性能 / 工具与模型 / 关于」,每块顶部都有一句话说明"这里管什么",所有选项都摆在明面上,不用再点开"高级…"去找。
- **首页**:第一次打开或者点顶栏 logo 会看到一个新的首页,有「开始一个新旅程」大按钮、最近编辑过的项目列表,还有三个现成的模板(旅行日记 / 电影感 / 快节奏)可以直接选着用。
- **功能引导气泡**:第一次用到某个功能时(比如导航条、自动挑选、镜头带、导出)会弹出一句话的小提示气泡,告诉你这是干什么用的,点一下"知道了"就不会再出现;如果想重新看一遍,设置的"关于"里有"重置新手引导"。
- **时间线化的镜头带**:镜头带上方新增了时间刻度和播放头(红线),播放时会跟着画面走,点刻度或点片段都能直接跳转到对应位置;片段还可以直接拖动两侧边缘微调入点和出点,不用回到监视器逐帧对。
- **导入剪映继续剪**:镜头带和导出面板现在都能直接把整理好的片段导出成剪映草稿,一键在剪映里继续做精细剪辑、转场、字幕这些 TripCut 不做的事。
- **剪映风格深色主题**:设置外观里新增一个偏冷、偏暗的深色主题选项,视觉上更接近剪映,默认不开启,喜欢的话可以自己切换。

## 剪映交接(R14)

- **试验草稿 + 人工确认**:如果你的剪映版本还没有核对过,导出面板的「剪映草稿」现在会多一个「仍然
  试着生成(试验)」按钮——点了会新生成一份带「试验」字样的草稿,不会覆盖或影响你剪映里已有的任何
  项目。生成后照着提示打开剪映看看这份草稿能不能打开,回来点「可以用」或「打不开」告诉软件结果:
  点「可以用」之后,这个版本以后默认直接生成草稿,不用每次都点试验按钮;点「打不开」也不影响别的
  导出方式,还可以再试一次。
- **剪映素材包**:不管你的剪映版本有没有验证过,现在都有一条稳妥的交接路——「剪映素材包」会把选中
  的片段按镜头带上的顺序编号导出成一堆视频文件,附一份「顺序.txt」说明每个文件对应第几段、哪一章、
  多长时间,拖进剪映的时间线,顺序就是文件编号的顺序。
- **集名/章节/配乐进草稿**:剪映草稿现在用你的集名命名(不再是一串代码);每一章第一个镜头的文件名
  会带上章节标记;如果这一集配了背景音乐,草稿里也会带上这条配乐轨。

## 分析更准

- **夜景不再误判欠曝**:以前曝光正常的夜景(路灯、窗户、手机屏这些高光)会被错判成"欠曝"或"太暗",
  现在改成同时看画面最亮的地方,正常的夜景不会再被误伤。
- **固定机位不再误判手持**:三脚架拍的、平稳跟拍的素材以前经常被判成"手持抖动",现在改进了抖动的
  判断方式,真正稳的画面不会再被贴上"抖"的标签。
- **切点更准**:场景切换的检测提高了取样密度,以前容易漏掉的硬切(尤其是暗场景之间的切换)现在能
  抓到更多。
- **老库会自动重新分析**:这几处都是判断逻辑本身的修正,已经导入过的素材库打开后会自动用新逻辑重新
  分析一遍,不需要手动操作,但会多花一点处理时间。

## 更稳

以下几项来自本轮压力测试发现的问题,修复已经写好但**尚未并入本版打包分支**,先记在这里,随下一次
打包生效:

- **缺失素材检测**:原片被移动或从外置硬盘拔掉之后,以前完全检测不出来;现在应用启动、关注文件夹
  同步、手动扫描、导出前都会真的检查文件还在不在,不在的话素材卡片会标「缺失」,导出时也会明确拒绝
  并说清是哪个文件、去哪里重新定位。
- **只读历史集**:回看已经导出过的旧集时,镜头带和导出内容以前会和当前正在编辑的集混在一起;现在
  严格按你正在看的那一集取数据,导出也会提示「回到当前集再导出」而不是悄悄导错内容。
- **状态条**:处理进度以前会卡在"正在分析 7/9"不动,或者明明还有任务却显示"后台空闲";现在状态跟
  真实的分析进度同步,失败的任务也会算作已处理,不会再卡死不动。
- **重试同目录**:「只重试失败的」以前会另开一个新文件夹从头编号;现在改成写回原来那个文件夹、沿用
  原来的编号,已经导出成功的文件不会被重复处理。

## 已知限制

- **R13 真机走查报告尚未产出**:剪映用户视角的「5 分钟脚本」真机复验计划已经开始记录,但截至本版打包时报告还没写完,不能保证剪映用户真机上手体验已经完全验证过。
- **导入剪映继续剪仍以白名单为闸**:目前只在检测到本机剪映版本在支持清单内时才把它设为默认导出方式,业主尚未在真实剪映环境里逐条验证过草稿能正常导入,不在清单内会看到"待验证"说明而不是直接可用。
- **首次启动偶发短暂白屏**:全新安装、从未激活过窗口的情况下第一次启动,窗口内容可能要等几十秒才出现(把窗口点一下置前就会立刻出全);已加了一个"正在准备工作台…"的过渡文案缓解视觉冲击,根本原因还在排查,日常从访达或程序坞打开大概率不受影响。
- **状态条的"预计时间"在超长素材上未完全验证**:目前只在几十条几十秒的短素材上验证过它不会误报,还没有拿几百条几分钟以上的真实长片测过它算得准不准。
- **拖动片段边缘调整入出点后,原有的星级评价不会带过去**:因为技术上会生成一个新的片段记录,旧片段打的星不会自动搬过来,需要重新打星。
- **一个界面出现两个"最主要"的按钮**:镜头带上「一键排入」和「导入剪映继续剪」目前都做成了同样醒目的主按钮,和"每屏一个主要操作"的原则有点冲突,是否收窄成一大一小,等业主拍板。
- **模板套用只做了一半**:首页点旅行日记 / 电影感 / 快节奏这些模板卡,目前只会新建一个项目并打开导入,还不会真的按模板自动挑片、排镜头,完整的模板套用留到下一版。
- **试验草稿还没有人真正在剪映里打开过**:上面「试验草稿 + 人工确认」这条路已经铺通,但目前只经过了自动化真机验证,还没有人手动点过「仍然试着生成」再在剪映里打开看过——这一步需要业主亲自确认(见业主行动清单)。
- **配乐轨的格式没有和真实剪映草稿逐项核对过**:草稿里的配乐信息参考的是第三方资料整理的格式,不是从一份真实的剪映草稿里比对出来的,如果配乐没能正常读出来,需要用真实剪映生成一份带音乐的草稿做参照重新核对。
- **压力测试发现的几处问题(缺失素材检测、只读历史集数据串台、状态条卡死、重试导出另开文件夹)修复已经写好,但还没有并入这一版的打包分支**,下一次打包会带上。

以上限制已记录在案,均不影响主线流程正常使用。

## 升级与边界

本版无新增数据库迁移,键位预设、引导气泡、深色主题全部存在设置里已有的键位体系中,不影响已有数据;镜头带的挑选→排列联动只是把原有的排序信息用起来,没有新表。没有删除任何界面或功能。

这一版目前还没有打版本标签、没有对外发布、也没有进入应用内更新源——只是先打好 QA 安装包放在业主桌面上等待确认。R13 剪映用户视角的真机复验尚在进行中,发布前会重新走查确认所有问题已经修好。等业主看过、点头之后,才会正式发布。
