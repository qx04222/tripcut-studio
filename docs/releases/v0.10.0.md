# 旅剪工作台 v0.10.0 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。0.8.3+ 用户会自动收到,点「重启完成更新」即可。

## 新界面

- 镜头带通栏:横贯整个窗口宽度,上面是媒体池 + 监视器,下面是状态条;窗口从 1280 到 1920 都是同一套布局。
- 检查器不再常驻占一栏:选中一段就从右侧滑出,Esc / 点空白 / ⌘2 收回;想一直留着就点「钉住」。播放中滑出也不会盖住视频画面,画面自动让位。
- 顶部只有一行:原来那条提示条撤了,它的文案进了首页四步卡和「下一步」按钮的悬停说明;工具链问题变成状态条左端的一个红点。
- 一屏只有一颗实心主按钮:各栏里的实心按钮全降为普通按钮,只留顶栏的「下一步」——你要点哪里,一眼就看得出来。
- 镜块只留三样东西:封面、时长、一行文件名;动作按钮悬停或选中时才出现。镜头带工具条收成两个下拉「按章节 ⌄」「附属:故事 ⌄」;后台真空闲时状态条只剩一句「后台空闲」+ 库名。
- 监视器:去掉画面里的小标签和假时码行,画面撑到栏边,传输条一行,热力直接画在进度轨上。

## 更顺的开头

- 首页不再有术语:一句话 + 「新建一集」/ 「继续上次」+ 最近的集;镜头带、章节、精选段这些词第一屏一个都不出现。
- 素材还在分析时也能先挑:主按钮写着「先挑已分析的 x/N 条」,点了就按已分析的挑,不再吃闭门羹。
- 教学只教一句:提示条、气泡、首启卡、空态归一个调度,同一时刻只出一个。
- 库是空的时候,导入抽屉只有一颗「选择文件夹」按钮。
- 第一次自动挑选不问任何问题,直接按全部素材 + 本机预算跑,挑完在提示里给「改范围 / 改时长」。

## 「显示全部功能」开关

- 设置 › 关于里新增,默认关。关着的时候镜头带附属只有 故事 / 音乐,检查器只留 评级 / 标签 / 章节 / 精选段 / AI 描述,设置只留 项目 / 播放与导出 / 工具 / 关于;技术检查、旅程、地点卡、模板、快捷键、性能这些进开关后面。打开即全部回来。

## 交给剪映,三张卡

- 导出首屏就三张大卡:「交给剪映」「导出视频文件」「整包交付」,其余都在「更多方式 ⌄」里。
- 「交给剪映」自动选路:按你机器上剪映的版本决定出草稿还是素材包,不用你选;记过保存位置后点一次即出,完成提示里「打开剪映」直达所在目录。用不了草稿的版本会用一行灰字说明差别。
- 素材包按章节分子目录,`顺序.txt` 标出章节边界;有转写的片段带同名 SRT,本集音乐一起放进去。

## 性能基准门禁

- 每次改动都要过:100 条固定夹具的整批分析耗时与峰值内存、真包启动时间(空库 <400 ms)、二进制与 DMG 体积(不超基线 +10%)。本版:二进制 25.3 MB(基线的 86%),启动中位 353 ms。

## 已知未验

- VoiceOver、深色主题、8 GB 机器本版没有真机走查。
- 素材包同名 SRT 只有单测,真素材未验;「打开剪映」按钮本轮没点(会拉起剪映)。
- 第一次导出仍会弹一次保存位置面板。

其余同 0.9.1。
