# 旅剪工作台 v0.11.2 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。0.8.3+ 用户会自动收到,点「重启完成更新」即可。

## 进度条重做:像剪映那样拖

- **帧级拖动**:监视器下面的进度条换成自绘的轨道——有时间刻度、波形、精彩程度热力条,拖动时按帧走,画面跟着手指,松开就停在那一帧;按下去就跳,不用先点再拖。
- **悬停看帧**:鼠标在轨道上停一下,就弹出那个位置的小画面和时码,不用真的拖过去看。
- **条上直接拖入出点**:入点 I / 出点 O 变成轨道上的两个把手,可以直接拖;两个把手不会互相穿过,拖动时显示区间长度。I / O 键照旧。
- **精选段放大**:选中一个精选段时,轨道默认只显示这一段前后一点(段外灰掉),看得更清;右侧「全片 / 片段」一键切换,记住上次的选择。
- **时码可输入**:点传输条的时码就能改,输 `分:秒.帧` 或 `秒.帧` 回车直接跳过去,Esc 取消,输错会标红。
- 键盘:轨道聚焦时 ←/→ 走一帧、⇧←/→ 走十帧、Home/End 跳到入点 / 出点;滚轮一格一帧(⇧ 十帧)。

## 镜头带「连播」:挑好的段连成一条粗剪先看看

- 镜头带标题栏新增「连播」(⌘⇧P,命令面板也有):按故事顺序把每个精选段从入点播到出点,自动接下一段,一路播完停在最后一帧——不用导出就能看这一版粗剪的节奏。
- 播放时监视器上方一行显示「连播 · 第 n/m 段 · 章 X」和整条镜头带的总进度,有上一段 / 下一段 / 停止 / 循环;镜头带上当前段高亮并自动滚进视野;状态条也写着「连播 n/m · 已播 / 总长」。
- 进度条同时画出当前这一段的范围和「第 n/m 段」;右键某个镜块可以「从这段开始连播」。
- 拖进度条、点别的素材或切工作台都会停止连播,不会留下悬着的定时器。原来媒体池那个「连播」(整条素材播完接下一条)不变。
