# 旅剪工作台 v0.11.4 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。0.8.3+ 用户会自动收到,点「重启完成更新」即可。

## 连播不再播你没选的片段

- **播到选段的出点就停,不会再往下放原片。**以前一段播完有时不切下一段,而是继续放你没挑的那一截;同一条素材里有两个精选段时,中间那段空隙也会被放出来。现在出点由播放器自己守着,到点就停。
- **换素材时先停在第一帧,定位好了再开播。**以前换到下一条素材会从头自己跑起来,你会先听见、看见几百毫秒没选的开头。
- **上一段 / 下一段、连着快速切段也一样。**段号、素材和入出点是一次换齐的,不会出现「段号已经变了、画面还是上一段」。

## 预览刻度和红色指针跟着你选的段走

- **刻度就是当前这一段的入点到出点。**以前刻度用的是 AI 建议的那 8 秒,和镜头带里保存的精选段对不上,所以怎么看都不对。
- **红色指针会从段首连续走到段尾。**以前播放位置超出那段错误刻度时,指针会被压在刻度边缘一动不动,看起来像卡住了(其实画面在动)。
- **AI 建议不再覆盖已经保存的精选段。**连播期间建议只当候选,不会填进入 / 出点栏。
- 连播时进度条固定按「片段」显示,「全片 / 片段」开关会变灰。

## 在镜头带上开始编辑时

- 拖动镜块、⇧ / ⌘ 多选、框选会停止连播,**素材会把当前这一段播完就停**,不会溜进没选的部分。想接着自由播,按一下播放键。
- 停止连播之后,播放器一定会真的停下来(以前在换素材那一瞬有机会停不住,原片会一直播到片尾)。

## 说明

- 本版只动播放与刻度,镜头带编辑、导入、分析、导出都没变。
- 完整复现证据、根因与验收记录见 `docs/qa/2026-09-22-playback-truth.md`。
