# 旅剪工作台 v0.4.0 · 未发布 / 预览

> 本文档记录的是候选内容。**是否公开发布、是否进入应用内更新源,由业主决定后再打 tag。**
> 在业主明确说「发」之前,这一版只以 QA DMG 的形式放在业主桌面上,不对外发布。

0.3.0 发出去给业主试用之后,我们请业主做了一遍真实的「导入素材 → 筛片评级 → 编排镜头 → 生成交付包」全流程走查,把过程中卡住、看不懂、按了没反应的地方一条条记下来(37 处),这一版是针对性修复。功能和界面风格延续 0.3.0,没有推倒重来。

## 这一版解决了什么

- **快捷键恢复**:上一版里点开一张素材卡片后,评级键(F/X/1–5/0)、播放键(空格)全部失灵,只有拿到最外层焦点时才管用——这一版起,点开卡片之后这些键正常工作。
- **同镜头分组更准**:上一版把同一天拍的、分辨率完全不同的十几条素材误判成"同一镜头的连拍",挤成一张看不出内容的卡片;现在按分辨率、画面比例、来源文件夹一起判断,不该合并的不会再合并,合并的也能展开查看每一条。
- **模板套用诚实提示**:套用故事模板时,如果没有足够的素材(收藏或高星级)可用,会直接说明原因并引导去挑素材,不会假装"已生成"却什么都没放进去。
- **检查器折叠可逆**:窗口缩小时右侧检查器会自动收起,但上一版这个收起状态有时候救不回来——放大窗口或手动展开之后就再也叫不出来了。这一版修好了,任何尺寸下都能找回。
- **平台画布方向**:小红书这类竖屏为主的平台,上一版给出的却是横版画布,导致预览带黑边;现在各平台的画布方向和它们的实际使用习惯一致,也可以在生成交付包时手动切换。
- **可拖动的播放进度条**:监视器新增了一条可以直接拖动定位的进度条;播放到结尾再按一次播放,会从头重新开始,而不是卡在原地没反应。
- **精选段区**:用"保存片段"功能截取的片段现在能在检查器里看到、试听、删除,不再是保存完就找不到。
- **标签、章节归属常驻显示**:检查器里评级、标签、所属章节这些信息不再看条件时隐时现,始终看得到。
- **空槽位「从媒体池选择」**:镜头带上空着的位置现在可以直接点一个按钮从素材池里挑一条填进去,不必非得靠鼠标拖拽(拖拽在部分系统环境下不够顺手,这算是一条备用路径)。
- **「加入当前章节」**:检查器和素材卡片上都新增了这个按钮,选中一条素材直接归入当前章节,同样是拖拽之外的另一条路。
- **导入/任务进度更清楚**:导入面板的进度信息改成了"索引 → 画质分析 → 运镜分析"三段式,每一步在做什么、进度多少都写明白,不再出现看不懂的内部代码。
- **抽屉记忆与文件夹命名**:关闭生成交付包的面板再打开,之前选的平台、时长这些设置会保留;导出的文件夹名称改用当前"集"的名字命名,不再是固定的默认名。
- **界面缩放**:系统设置里的界面缩放选项现在整套界面(包括素材卡片文字、监视器工具条这些)会一起放大,不再只有部分控件跟着变。
- **首启只弹一次**:引导弹窗过去会在切换新旧界面时反复出现;现在只在真正第一次使用时出现一次。
- **恢复页新风格**:软件异常退出后重新打开时的恢复提示页面换了排版,标题不会再折成怪异的断行,"进入工作台"按钮始终能第一眼看到不用往下翻。
- **Whisper 模型导入**:设置页新增了转写模型的下载地址、校验值和一键导入入口,不再需要自己摸索文件该放哪。
- **新建集**:切换到新的一集时,现在有明确的"新建集"入口。
- **LUT 导入**:调色预设(LUT)新增了导入按钮,可以直接添加自己的文件。

## 已知限制

- **播放器打点键(I/O)在新界面主屏还未接通**:进入全屏沉浸模式后可以正常打点,但在主屏监视器里用 I/O 键还没有反应,下一版会补上。
- **竖版交付的"参考粗剪"视频画面暂时仍是横版**:抽屉和交付说明里都正确显示了竖版画布,但生成出来的参考粗剪片段目前还是横版加黑边,正在修。
- **镜头带上的时长数字偶尔不准**:部分镜头片段和章节标题显示的时长和实际不符,正在修。
- **部分缩略图仍是占位图标**:素材池里的封面缩略图已经修好,但镜头带上的小卡片和检查器里的同镜头切换条,缩略图暂时还是占位图,正在修。
- **切换到新建的集之后,监视器和检查器有时还停留在旧集的素材上**:需要手动重新选择一次,正在修。
- **界面缩放到 130% 时,素材卡片的文件名可能被裁切**:其余部分都能正常缩放。
- **拖拽功能仍需要在真机上进一步验证手感**:目前已经补充了不依赖拖拽的操作路径(见上文"加入当前章节"),拖拽本身不影响主线操作。

以上限制已记录在案,`fix/r10-regressions` 分支正在处理,发布前会重新走查确认。

## 升级与边界

新增数据库迁移一条(只对现有的"平台预设"表加了一列并回填默认值,不影响已有数据);没有删除任何界面或功能,旧的四页式界面仍可以在设置里临时切回。

这一版目前还没有打版本标签、没有对外发布、也没有进入应用内更新源——只是先打好 QA 安装包放在业主桌面上等待确认。等业主看过、点头之后,才会正式发布。
