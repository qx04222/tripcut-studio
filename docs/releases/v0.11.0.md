> 未签名、未公证的预览版(ad-hoc 签名)。0.8.3+ 用户会自动收到,点「重启完成更新」即可。

## 照片有自己的工作台了

- **视频和照片彻底分开**:同一集里现在有「视频工作台 / 照片工作台」两个标签。视频池、自动挑选和镜头带只处理视频；照片停留时长不会占用视频预算，也不会混进视频故事顺序。
- **连拍先成组再挑**:照片按拍摄日期分组，相似连拍折叠在一起，疑似废片会靠后显示。可以直接看清组里哪一张更锐、更稳，再选代表照片。
- **照片监视器按照片来设计**:静态大图、缩放与拖拽、EXIF 信息、1–5 星、F 收藏和 X 淘汰都集中在同一处。交互参考 pianke-ai-select 的高效选片思路，并按 TripCut 的本地素材库和撤销链路重新实现。
- **擂台二选一**:从一组相似照片启动擂台，两张一轮做选择；结果只替换这一组的代表照片，整组操作可以用 ⌘Z 撤销。
- **一句话挑照片**:输入「挑 7 张照片」即可得到一版结果；结果面板里能移除、换一张或启动擂台继续精挑。
- **交付时各走各的目录**:本集含照片时，素材包和整包交付会分别生成 `视频/` 与 `照片/`，各自带 `顺序.txt`；照片顺序与精选带一致。

## 说明

- 照片工作台支持常见照片格式与 HEIC；原片仍保持只读，交付时另行输出。ARW/DNG 本版作为伴随原片交付，暂不直接解码检视。
- 这版保留原有视频工作台的布局与操作，视频壳截图与 0.10.2 基线逐像素一致。
