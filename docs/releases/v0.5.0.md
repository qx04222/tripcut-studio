# 旅剪工作台 v0.5.0 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名):首次打开需在「系统设置 → 隐私与安全性」里允许,
> 或右键 →「打开」。旧版可通过应用内更新升级到本版。

0.4.0 修完首次使用可用性问题之后,业主提了三条新诉求:软件能不能帮忙选精选片段、导出能不能更简单一点、播放器能不能更聪明一点。这一版就是照这三条做的,同时把界面上残留的内部术语和多余步骤做了一轮清理。

## 这一版解决了什么

- **自动挑选精选段**:软件现在会分析每条素材里"哪一段最好看"(画面清不清晰、运动幅度合不合适、曝光正不正常、有没有声音),给出建议片段。选中一条素材,监视器进度条下方会出现一条热力条,标出建议的位置;按 `Enter` 就能把当前建议采纳成精选段,`N`/`⇧N` 可以在多条建议之间切换。
- **一键挑选一整集**:镜头带工具条上新增"自动挑选"入口,选好范围(收藏、评分较高、或全部)和大致时长,点一下就能按章节均匀地把好片段挑出来,挑得不满意可以整批撤销,不会影响自己手动挑的片段。
- **从最精彩的地方开始播放**:选中一条素材,默认会直接从它最出彩的那一刻开始播放,而不是永远从头看起(可以在设置里关掉)。
- **播放器更聪明**:播完一条自动接上下一条(可关);逐帧前进/后退看清楚每一帧;前进后退 5 秒快速跳转;给一段素材打好入出点后可以循环播放反复看;静音状态会记住,换素材不会重置;在素材卡片上滑动鼠标能看到一段动态预览,不用点开才知道拍的是什么。
- **快速导出**:交付面板默认变成"快速导出"——只导出挑好的精选片段和收藏的素材,不再需要经历完整交付包的一长串设置,导出到上次用过的文件夹,做完后直接可以在访达里找到文件。检查器和素材列表里也新增了"导出所选…"的入口,选中几条想要的直接导出。
- **界面更简单**:
  - 首次打开软件不再是一屏看不懂的工具链检查清单,改成"导入素材 → 挑选片段 → 导出"三步引导卡片。
  - 设置页从九个分类收进"常用 / 工具与模型 / 关于"三大区,常用的项目直接摆在最前面,不常用的项目收进"高级…"里,不占地方。
  - 界面里出现的内部术语(比如某些内部代码名、技术参数缩写)统一换成了看得懂的说法。
  - 每个界面只保留一个最显眼的主要操作,次要选项收起来,减少"这么多按钮我该点哪个"的困惑。
  - 遇到错误或者空白状态时,现在会用一句话说清楚"发生了什么、接下来怎么办",而不是甩出一段技术性提示。

## 已知限制

- **播放变速是模拟出来的效果**:2 倍速/4 倍速快进和反向播放目前是靠"暂停后快速跳位置"模拟的,画面会有轻微跳动感,不是真正丝滑的变速播放;要做到真正的变速需要改动播放引擎最底层的部分,安排在下一版。
- **音量大小不会被记住**:静音状态会记住,但具体的音量高低目前还没有记忆功能。
- **"有没有说话"的判断偏宽松**:目前是用声音大小粗略判断的,没有语音识别模型辅助时,响亮的环境声也可能被当成"有人声",带了转写文字的素材判断会更准。
- **完整交付包里仍有少量专业术语**:快速导出已经全是大白话,但退到次选位置的"完整交付包"选项里还留了一些偏技术性的说明文字,下一版会一并清理。
- **空格键在某些情况下可能不响应播放/暂停**:真机上发现过点击素材卡片后空格键偶尔失灵的情况,目前可以用 `K` 键作为替代,根本原因还在排查。
- **暗场/夜景素材的"最精彩片段"判断可能偏保守**:因为曝光判断标准对暗光环境比较严格,夜景素材的建议分数可能整体偏低(相对排序仍然有效)。

以上限制已记录在案,均不影响主线流程正常使用。

## 升级与边界

新增数据库迁移一条(只新增了一张记录"每段素材精彩程度"的表,给"精选段"表加了两个标记列,不影响已有数据)。没有删除任何界面或功能。

这一版目前还没有打版本标签、没有对外发布、也没有进入应用内更新源——只是先打好 QA 安装包放在业主桌面上等待确认。真机复核的第二轮尚在进行中,发布前会重新走查确认所有问题已经修好。等业主看过、点头之后,才会正式发布。
