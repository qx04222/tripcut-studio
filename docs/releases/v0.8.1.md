# 旅剪工作台 v0.8.1 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。**从这一版起软件会自己更新**:启动后自动检查、后台静默下载,
> 下载好只提醒一次「重启完成更新」。0.8.0 用户请在 设置 › 关于 点一次「检查更新」升到本版,之后就不用再手动下载了。

## 自动更新

- 默认开启:启动 30 秒后检查一次(每天最多一次),有新版本就在后台下载,状态条显示「正在下载更新 42%」,下载期间照常使用。
- 下载好后只弹一条提示:「更新已下载 · 重启完成更新 / 稍后 / 跳过这个版本」;退出软件时自动完成替换。
- 设置 › 关于:「自动更新」开关、「有新版本时先问我再下载」、「检查更新」(结果内联显示)、当前版本与上次检查时间、更新说明。
- 断网静默;下载或校验失败会用白话说明并给出下载页链接;替换前一定先校验签名。

## 为什么之前"每次都要重新下载"

更新机制本身是通的,但过去只有手动点「检查更新」才会查,而且桌面上装的多是测试包(和 GitHub 上的正式版对不上号),所以点了也显示「已是最新」。这一版把自动检查和后台下载补上,并把正式版都发到了 GitHub。

其余内容与 0.8.0 相同。
