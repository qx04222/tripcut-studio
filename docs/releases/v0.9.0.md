# 旅剪工作台 v0.9.0 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。0.8.3+ 用户会自动收到,点「重启完成更新」即可。

## 更像一个 Mac 软件

- 中文原生菜单栏:旅剪工作台(关于 / 检查更新… / 设置… ⌘,)、文件(导入 ⌘I / 导出 ⌘E)、编辑(撤销 ⌘Z / 重做 ⇧⌘Z)、显示(命令面板 ⌘K / 全屏)、窗口、帮助(使用手册 / 快捷键表)。
- **⌘Z 终于能用了**:之前被系统默认的英文 Edit 菜单吞掉,撤销栈键盘上按不到。
- 外接屏拔掉后窗口不再跑到屏幕外(启动时自动拉回居中);全屏尺寸不再写坏窗口尺寸。
- 关闭窗口时后台还有任务会先问一句「还有 n 个后台任务没做完」。
- 系统弹的权限框、打开面板等文案变中文;桌面/文稿/下载/外置盘/网络盘的权限说明写清用途;被拒后有「去系统设置」按钮。
- 软件本体 41.8 MB → 26.5 MB。

## 设置更全

- 通知:交付完成 / 批量分析完成 各一个开关;首次通知前先说明。
- 工具与模型:三个路径框各有「恢复内置」。
- 后台任务:「清空全部失败」。
- 项目与缓存:「更改缓存位置…」(可放外接盘)、「多久没用就自动清掉」。
- 关于:「导出诊断包…」(一个 zip,不含任何路径)、「打开日志目录」;运行日志现在真的落盘(7 天)。

## 更精致

- 39 枚图标按统一网格重画(齿轮 16 px 清晰,拖动把手/更多不再是墨点),新增 标签 / 相似镜头 / Take / 槽位 四个专属图标。
- 应用图标改为 macOS 圆角方形,尺寸按 Apple 规范,程序坞里不再大一号。
- 顶栏在窄窗口折叠成「第 ④ 步 · 导出 ⌄」胶囊;更新就绪时不再两颗实心按钮;媒体池、监视器、镜头带工具条、首页、状态条逐处对齐;深色主题焦点环修正。
- 样式门禁覆盖全部车道样式,今后不再漂移。

## 更快(M 系列全内存档)

- 按机器能力自动分四档(≤8 GB 低配 / 16 GB 省内存 / 32–64 GB 标准 / ≥64 GB 且多媒体引擎 高性能),解码并发按素材类别计量(1080p 一份、4K 两份、4K 10-bit 三份),不再一律写死 4 路:本机 M5/32 GB 整批分析 −9%(独占 A/B 中解码预算 4→8 为 −42%);8 GB / 16 GB 行为逐项不变。
- 设置 › 性能:「后台干活的力度」省电 / 平衡 / 全速 三挡取代原来 1–8 那个实测无效的旋钮(低配、省内存档只给两挡)。
- 启动:补扫与启动快照挪到窗口出现之后,开窗前耗时 251 → 133 ms(1344 条库)。
- 低电量模式自动降到省电档;启动快照总量封顶 1 GB(设置里可见占用);媒体池交互态渲染 −8~11%。

## AI

- 「AI 描述」现在真的看过画面:八维标签、画面文字、口播转写、最佳时刻都进了描述;没有云端也有一句本地描述。
- 评测语料入库(21 条真素材人工真值 + 8 条合成片),基线报告随仓库;后续每次改打分都要过它。
