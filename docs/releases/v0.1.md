# 旅剪工作台 v0.1

> 把一整天的旅途素材，收束成一条可以开始剪的故事。

![旅剪工作台 v0.1：房车营地里的离线素材工作台](https://github.com/qx04222/tripcut-studio/releases/download/v0.1/tripcut-v0.1-release-hero.png)

*从相机卡和移动硬盘，到一条可以继续剪的故事线。主视觉为概念插画，不包含用户素材。*

这是 TripCut Studio 的第一个公开预览版本，面向旅居、房车生活和旅行 Vlog 创作者。它不取代剪映，而是在剪映之前完成最耗时间的整理工作。

![TripCut v0.1 五步工作流：只读导入、播放筛选、故事结构、稳定交付、继续剪辑](https://github.com/qx04222/tripcut-studio/releases/download/v0.1/tripcut-v0.1-workflow.png)

## 这一版解决什么

旅行拍摄往往留下大量零散片段：风景、赶路、驻车、做饭、人物互动和意外瞬间混在多个相机与目录里。真正困难的不是“有没有素材”，而是如何快速找到值得进入故事的那一条。

v0.1 把这段工作集中在一个本地工作台里：

| 阶段 | TripCut 帮你完成 |
| --- | --- |
| 导入 | 只读索引相机卡、移动硬盘、本地目录与 watched folder |
| 筛片 | 4K HEVC/10-bit 播放、收藏、拒绝、星级和质量角标 |
| 选段 | 用 I/O 标记入点与出点，保存可交付的精选段 |
| 叙事 | 用 Episode、章节、Beat 和 Storyboard 收束故事顺序 |
| 交付 | 生成精选片段、1080p 参考粗剪、CSV 镜头表、字幕与中文说明 |

## 为长期旅行设计

- **原片只读**：不移动、不覆盖、不删除相机文件；
- **跨集记忆**：封存 Episode 后仍能识别过去用过的镜头；
- **离线可用**：核心整理与交付不依赖云服务；
- **可恢复**：后台任务、快照和交付状态都有明确边界；
- **人工优先**：AI 建议与用户确认结果分开保存；
- **面向剪映**：默认出口是稳定交付包，不强迫创作者迁移最终剪辑工具。

## 本地媒体能力

预览包内提供固定版本的 FFmpeg、FFprobe、libmpv 和 whisper-cli，并对原生动态库、来源哈希和许可证进行逐项审计。Whisper 模型不随包分发，L3 大模型增强默认关闭。

## 下载前请注意

这是面向测试者的 Apple Silicon 未签名预览版：

- 使用 ad-hoc 签名，没有 Apple Developer ID 或 notarization；
- macOS 首次打开时可能显示安全警告；
- 没有自动更新；
- Chinese-CLIP 与剪映原生草稿仍属于实验能力；
- 请勿用唯一一份原片测试 Alpha 软件。

安装时请遵循附件 `UNSIGNED_PREVIEW.md`，不要关闭 Gatekeeper，也不要运行来源不明的解除隔离命令。

## 从这里开始

1. 从 [GitHub Release](https://github.com/qx04222/tripcut-studio/releases/tag/v0.1) 下载 `TripCut-Studio_0.1.0_20260903T211000Z-v0.1-r1_preview_aarch64.dmg` 与 `SHA256SUMS.txt`；
2. 核对校验和；
3. 阅读 `UNSIGNED_PREVIEW.md`；
4. 用一份有备份的短素材完成“导入 → 筛片 → 精选段 → 稳定交付包”；
5. 把实际体验、崩溃日志或可复现步骤提交到项目 Issue。

欢迎第一批创作者参与测试。最有价值的反馈不是“功能多不多”，而是它有没有真正缩短你从拍摄结束到开始剪辑的时间。
