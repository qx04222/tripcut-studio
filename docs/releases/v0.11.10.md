# 旅剪工作台 v0.11.10 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。0.8.3+ 用户会自动收到,点「重启完成更新」即可。

## 「自动」预览画质不会再莫名退回糊的预览

- 0.11.9 里「自动」档有时会显示「原片掉帧,改播代理」,之后一直播 540p 的预览小文件,只有暂停才是原片。**原因不是你的素材或拍摄,也不是机器带不动**:当监视器被面板、抽屉、设置页或提示气泡挡住(或窗口最小化)时,画面暂停刷新,播放器却把每一帧都记成「掉帧」,于是误判成「原片播不动」。
- 现在只在监视器**看得见、1 倍速播放**时,按**实际画到屏幕上的帧数**判断:连续几秒明显低于素材帧率(低于 90%)才算播不动;被挡住、不在屏幕上、倍速、切换来源时一律不评判。
- 实测:4K 50 fps 10-bit(含 HLG / PQ、4:2:0 与 4:2:2)在「自动」档连续播 60 秒,全程原片,约 49.5 fps,0 次降级;挡住监视器 5 秒再关掉,仍然是原片。

## 真播不动时退到 1080p,而且说清楚原因

- 如果真的播不动,改用 **1080p** 预览(还没有就在后台生成,生成好之前临时用 540p),角标写「原片播放不动,暂用 1080p 预览」。
- 同一条素材在本次打开应用期间会记住这个决定,不会每次都先卡几秒再退。换素材重新判断。
