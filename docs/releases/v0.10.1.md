# 旅剪工作台 v0.10.1 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。0.8.3+ 用户会自动收到,点「重启完成更新」即可。

## 挑完告诉你为什么

- 自动挑选一结束,右侧滑出「为什么是这些」面板:每段一行 —— 封面、时长、分数和一句白话理由(「清晰 · 曝光正常 · 有声音」这种),同一机位被去重掉的兄弟段点开就能看。
- 面板上每段都能动手:「不要这一段」直接从带上拿掉;「换一段」换成同一条素材里的另一段,位置不变;右上「全部撤销」把这一批整个收回,⌘Z 也一样。
- 挑完的提示说的是实际总时长,不再是目标预算;第一次挑选不问任何问题,挑完再给「改范围 / 改时长」。

## 一句话挑片

- 「自动挑选精选段」面板最上面是一个输入框:写一句「挑 60 秒,风景为主,按时间顺序」回车就行,软件本地读懂中文里的时长、顺序、偏好,不联网;接了大模型的机器会读得更细,没接的静默走本地规则。
- 首页多了三句现成的:「旅行日记」(90 秒,按时间顺序,有人说话的留着)、「电影感」(60 秒,少运动多稳定,风景为主)、「快节奏」(30 秒,多运动,按分数)。点一张就出一版,面板里回显原句。

## 模型一键安装

- 设置 › 工具与模型:每个模型一张卡 —— 未安装 / 下载中 / 已安装。「画面理解模型」约 750 MB,「转写模型」约 1.6 GB,点「安装」后台下载,边下边校验 SHA-256,可取消、失败可重试,下载中不落半个文件。
- 状态条一句进度「正在下载画面理解模型 25%」;首启气泡里的「安装」是同一个入口。

## 主题与界面

- 主题只剩三档:跟随系统 / 浅色 / 深色(原「剪映风格深色」升格为唯一的深色,旧偏好自动映射)。
- 浅色下,监视器、镜头带和状态条改用深底,看画面不晃眼。
- 深色主题 43 个场景逐一走查,截图基线进门禁,以后改样式偏差超过 0.5% 会被拦。
- 导入后立刻按日期 › 时段出卡片分组,抽屉自动收起,状态条「已导入 N 条 · 共 X 分钟」,分析在后台继续。
- 「自动挑选精选段」弹层开着时,顶栏「下一步」仍是屏上唯一一颗实心按钮。

## 已知

- 画面理解模型装完后,画面搜索还需要本机的 Python 运行环境(本版不随包分发;个人机已具备的照常可用),没有的机器会显示「运行环境还没就位」,模型先装着,组件到位后自动启用。
- 「换一段」换出去的旧段不进 ⌘Z 栈,只能靠面板「全部撤销」整批收回。
- 结果面板底色带一点透明,镜头带镜块会隐约透出来。
- 分析进行中、预估不出剩余时间时,状态条只显示「已导入 N 条 · 共 X 分钟」+ 进度条,看不到「正在分析 n/m」。
- VoiceOver、8 GB 机器本版没有真机走查。
