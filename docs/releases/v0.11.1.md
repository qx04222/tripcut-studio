# 旅剪工作台 v0.11.1 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。0.8.3+ 用户会自动收到,点「重启完成更新」即可。

## 照片只做照片的事

- **导出改名「导出精选照片」**:照片工作台不再提「交给剪映」。导出把挑好的照片(原图 + 伴随的 RAW/xmp)连同 `顺序.txt` 送到你选的文件夹,不再生成三卡选择或剪映相关的产物。
- **素材包 / 整包交付回到纯视频**:两个交付口子里不会再混进照片,项数与预计时长按视频自己算,不再把照片算进去。
- **Sony ARW / DNG 可以直接看了**:卡片缩略图和静态检视直接显示 RAW 画面(角标标「RAW」),不用等交付才能看清拍到了什么。本版在真机 Sony A7R III 上验过;iPhone ProRAW、Leica、GR 的 DNG 还没有真实样张,解码质量待补验证。
- **导出中断可以接着导出**:导出到一半被打断(比如应用被强制退出、目标文件夹一度不可写),重新打开会看到「上次导出未完成」的入口,点进去能看到卡在哪些文件、继续导出或撤销已经复制的部分。全程原片只读,过程用哈希核对,不会破坏原始素材。
- **顶栏 / 状态条不再夹带视频概念**:在照片工作台看到的都是「张」「已选」,不会出现视频那套「段」「章」「分钟」的说法。

## 说明

- 设置里新增三项画质指标(地平线端正、局部曝光、主体清晰)的展示,默认不参与打分;需要在「关于」页打开「显示全部功能」才能看到,标定完成前不生效。
- ARW/DNG 真实样张仍只覆盖 Sony A7R III;iPhone ProRAW、Leica Q、GR III 的样本还缺,解码质量与真机预览大小暂不能外推。
- Chinese-CLIP 画面语义搜索、Python 运行时打包状态与 0.11.0 一致,不随本版变化。
- 完整无人值守验收记录见 `docs/qa/2026-09-21-unattended-r21-w3.md`。
