# 旅剪工作台 v0.8.2 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。装了 0.8.1 的用户会自动收到这一版(启动后自动检查、后台下载、重启完成);
> 0.8.0 用户在 设置 › 关于 点一次「检查更新」。

## 修的两个交付级问题

- **剪映素材包 / 导出片段全部失败「Unrecognized option 'allow_sw'」**:导出以前按系统 PATH 去找 ffmpeg,别的电脑上可能找到一份不带硬件编码的 ffmpeg。现在导出一律优先用软件自带的 ffmpeg;万一还是没有硬件 H.264,自动换软件编码(libx264 → mpeg4)并在结果里说明;失败信息会写明用的是哪份 ffmpeg;入点正好在关键帧的精选段直接无损截取,不再转码。
- **切到下一条素材从上一条停住的位置开始播**:换素材瞬间的走带命令(定位 / 播放 / 逐帧 / JKL / 拖进度条 / 镜头带点位)全部按素材归属校验,Rust 侧再加一道闸,旧素材的命令不会落到新素材上;新素材一律从头(或「从最精彩处」开着时从它自己的最佳点)开始。
