# 旅剪工作台 v0.1.1 · 未签名预览版

这一版让素材库更容易重新开始，也让误导入可以停止、撤销和重新选择。

## 素材库与导入

- 侧栏新增素材库管理：新建独立空白库、保存并重启切换、从列表移除和恢复。原有素材库直接保留，无需搬迁。
- 每次导入单独显示批次，可停止本批导入与关联分析，或撤销本批新建的素材。
- 支持勾选移除、清空当前集素材、清理重复/失败提示；确认前显示素材、评分、精选段与缓存的影响数量。
- 移除只清理 TripCut 记录与派生缓存，不删除原始视频；清理前保存数据库快照。已封存集受保护，存在交付任务时拒绝移除。
- 新关注文件夹默认不自动同步；用户可按需开启。取消或移除会暂停相关目录同步，避免素材被自动重新导入。
- 取消、失败或撤销后可以重新选择同一文件夹。重复检测覆盖并行任务，较大文件的首尾指纹相同时再核验完整内容。

## 分析、界面与稳定性

- 运镜分析采用双帧流式处理，减少长视频采样的内存占用；保留既有计算结果。
- 修复纯色视频分析无法写入数据库、过期任务污染新尝试、取消转写仍提交和解码超时等待问题。
- 区分索引、画质与运镜进度；减少重叠轮询并在隐藏时暂停。
- 增大关键文字与按钮，修复候选组展开裁切及表头横向滚动错位。

## 升级与边界

数据库升级到 schema 29，并在迁移前保存快照。升级后的库不要用旧版应用打开；需要回退时使用升级前的数据库快照。切换库会等待运行中的任务结束，未开始的任务留在旧库，返回时继续。

这是 Apple Silicon / arm64 的 ad-hoc 签名预览版，没有 Apple Developer ID 或 Apple 公证。请核对 SHA-256；详见 [未签名预览版说明](https://github.com/qx04222/tripcut-studio/blob/v0.1.1/docs/UNSIGNED_PREVIEW.md)。本版未更换应用内 AI 模型，模型仍由用户配置。目标电脑性能、真实模型长时间运行与干净机器验收不包含在本次结果中。
