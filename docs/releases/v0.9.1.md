# 旅剪工作台 v0.9.1 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。0.8.3+ 用户会自动收到,点「重启完成更新」即可。

## 挑选更聪明,也说得清为什么

- 时刻分新增「画面少见」一项(有画面向量时生效,没有时自动不算),不再只看清晰 / 运动 / 曝光 / 声音。
- 「有人声」判定改为看人声频段与起伏,纯音乐不再被当成口播(真素材负控 3/7 → 7/7,口播召回不变)。
- 自动挑选:每一段都记下「为什么选它」(检查器里能看到);同一机位连拍只取最好的一段;每段可单独「不要这一段」,整批撤销仍在。
- 搜索:文本搜画面能定位到「第 n 秒」,点结果直接跳到那一秒;相似镜头按逐帧向量聚类。
- 首次启动会重算一遍时刻分(版本升级),大库需要几分钟,进度看底栏。

## 更像一个 Mac 软件(续)

- 把视频或整个文件夹拖到窗口任意位置、或拖到程序坞图标,都直接导入;「打开方式」也行。
- 后台任务运行时程序坞图标显示进度。
- 「交付完成」通知带「在 Finder 中显示」。
- 外置盘弹出后素材标为暂时缺失而不是报错;iCloud 里没下载到本机的文件会提示并可「现在下载」;缓存位置指向已弹出的盘时自动退回内置位置。

其余同 0.9.0。
