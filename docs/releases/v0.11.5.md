# 旅剪工作台 v0.11.5 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。0.8.3+ 用户会自动收到,点「重启完成更新」即可。

## 连播不会再卡在第一段末尾

- **用入点 / 出点打点保存的段,连播能正常接到下一段了。**0.11.4 里出点正好落在某一帧上时,连播会停在第一段最后一帧不动,也不切下一段。现在到点判断留了半帧余量。

## 切到另一条素材时不再闪一下开头

- **换素材直接从入点那一帧打开并停住,再开播。**以前会先闪一下新素材最开头的两帧(约 70–90 ms)再跳到入点;现在这段错帧是 0。检查器里「复播精选段」同样受益。

## 进度条

- **连播被镜头带编辑打断之后,在进度条上拖 / 点只会定位,不会自己开播**,按播放才继续。正常播放时拖进度条、松手照常接着播,没变。
- 连播时进度条的读数把「时码 · 第 n/m 段」放在一起,段号和位置不会再一瞬间对不上(读屏 / 辅助功能可见)。

## 镜头带章节归属更稳

- 跨章拖过的段,如果它所在的章后来没了,会回到素材原来的章,而不是掉进「未分章」、导出时章名变空。
- 只记录「和素材原章不一样」的归属,不再给每一段都重复写一份。

## 剪映草稿:字幕可以直接进时间线(试验)

- 导出 → 剪映草稿里多了一个开关「字幕写进时间线(试验)」,**默认关**。打开后,每段字幕按入点换算成时间线时间,写成一条文字轨「TripCut字幕」,同时在 `TripCut字幕/时间线字幕.srt` 另存一份,方便核对。原来的逐素材 SRT 照常输出。
- 开关关着时,生成的草稿和 0.11.4 一字不差。
- 这是试验功能:剪映 11.4 上还需要你打开一次确认文字轨正常。**如果带字幕的草稿打不开,先关掉开关再生成一份**——关着能开说明是字幕轨的问题,这时不要点「打不开」。
