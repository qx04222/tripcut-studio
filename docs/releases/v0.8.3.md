# 旅剪工作台 v0.8.3 · 未签名预览版

> 未签名、未公证的预览版(ad-hoc 签名)。

## 一条重要修复:更新下载完成后界面不再冻住

0.8.1 / 0.8.2 在后台下载好新版本后会**立刻在运行中替换软件本体**,macOS 上这会让界面整个没反应(点什么都不动)。
从 0.8.3 起,下载好只暂存,真正替换放在你点「重启完成更新」或退出软件时。

**如果你现在用的是 0.8.1 / 0.8.2**:收到这次更新后界面可能会卡住一次 —— 直接退出(⌘Q 或强制退出)再打开,打开的就是新版本,以后不会再出现。

其余内容与 0.8.2 相同(修好导出失败与切素材起点;顶栏齿轮旁新版本提醒;设置图标改齿轮;素材可移到其他集)。
