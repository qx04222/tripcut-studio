# 旅剪工作台 v0.2.1 · 未签名预览版

这一版给故事板加了缺口检测与云端补镜：接不上的镜头会被自动标出来，需要时可以向 MiniMax 下单生成候选镜头，生成结果直接回流成素材库里的普通素材。

## 故事板

- 故事板新增「缺口」卡片：自动检测叙事里接不上的镜头缺口（含朝向类缺口的正确归类），可点开「生成候选」发起云端补镜。
- 生成任务的轮询覆盖到全部非终态状态，直到候选「已入库」或失败/取消才停止，卡片不会再卡在「生成中」。
- 生成物入库后作为该缺口的备选镜头，随时可在故事板里替换使用；生成的素材会打上「AI 生成」徽章，与实拍素材区分。

## 云端补镜（MiniMax）

- 设置页新增「云端补镜（MiniMax）」分区：粘入自己的 API Key（存于系统钥匙串），按需发起生成，全程按月度预算熔断、绝不自动提交。
- 需自备 MiniMax API Key，按量付费（platform.minimax.io 自行注册充值）；提交生成请求时，画面首尾帧截图与提示词会上传至 MiniMax 服务端用于生成。
- 设置页附费用账本，记录每次提交的预估花费。

## 已知限制 / 待业主验证

- 真实 MiniMax 接口的端到端验证（真实网络请求、真实计费）需要业主自行注册充值并粘入 API Key 后验证，本版内部测试基于本地假服务器。
- 本机安装的剪映在开发期间自动更新到 11.4.13169（超出既有白名单 11.3.0），草稿文件格式变为加密，金丝雀脚本无法逐字段比对；应用仍会拒绝为该版本生成草稿，不会静默产出打不开的文件；需业主用真实 11.4 剪映打开一份 11.3.0 格式草稿以确认新版本能否读取，在确认前交付页继续对该版本提示「不支持」。

## 升级与边界

数据库 schema 从 40 升到 41，并在迁移前保存快照。**升级后的库不要用旧版应用打开**；需要回退时使用升级前的数据库快照。

这是 Apple Silicon / arm64 的 ad-hoc 签名预览版，没有 Apple Developer ID 或 Apple 公证。请核对 SHA-256；详见 [未签名预览版说明](https://github.com/qx04222/tripcut-studio/blob/v0.2.1/docs/UNSIGNED_PREVIEW.md)。Whisper 转写模型与 Chinese-CLIP 语义检索模型仍由用户自行配置，不随安装包分发。
